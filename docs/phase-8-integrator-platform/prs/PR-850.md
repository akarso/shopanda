# PR-850 — Plugin SDK Package

Status: done

## Summary

- Ship `pkg/pluginsdk` typed registration helpers for pricing, import row hooks, and sync jobs
- Provide `After` / `Before` pricing position helpers and cron/event sync job wrappers
- Adopt SDK in cartdemo, importdemo, and warehousedemo reference plugins

## Why

Tracks B–E shipped raw `plugin.App` registration APIs across pricing, import, integration routes, and sync jobs. Integrators wiring many plugins need lower-ceremony, discoverable helpers without re-learning string position formats each time.

## Scope

- `pkg/pluginsdk/doc.go` — package overview
- `pkg/pluginsdk/sdk.go` — `New(app, pluginName)` entry point
- `pkg/pluginsdk/pricing.go` — `Pricing().Register(step, After("promotions"))`
- `pkg/pluginsdk/import.go` — `Import().RegisterRow` / `RegisterProductRow`
- `pkg/pluginsdk/sync.go` — `Integration(slug).RegisterCron` / `RegisterOnEvent`
- Unit tests for pricing positions, import registration, sync jobs
- Reference plugin updates: `cartdemo`, `importdemo`, `warehousedemo`

## Out Of Scope

- Registration report CLI (PR-851)
- Replace-by-name pipeline steps (PR-852)
- Hooks/composition SDK wrappers (hooks remain direct `app.Hooks` for now)
- Runtime plugin discovery

## API

```go
sdk := pluginsdk.New(app, p.Name())

sdk.Pricing().Register(myStep, pluginsdk.After("promotions"))

err := sdk.Import().RegisterProductRow(100, remapHandler)

err := sdk.Integration("warehousedemo").RegisterCron("warehouse.stock", "@every 5m", handler)
err := sdk.Integration("acme").RegisterOnEvent("pim.enrich", "catalog.product.updated", handler, pluginsdk.MaxRetries(3))
```

Stable hook names, step anchors, and sync triggers remain in `pkg/extapi`.

## Validation
