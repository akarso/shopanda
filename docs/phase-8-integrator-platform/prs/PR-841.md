# PR-841 — Integration Client Bootstrap

Status: done

## Summary

- Ship `pkg/integrationsdk` stdlib-first HTTP and GraphQL clients for outbound integration plugins
- Provide timeouts, bounded response bodies, structured logging, and predictable error types
- GraphQL client built on the HTTP client (single logging/timeout policy)

## Why

PR-840 added sync job registration; reference warehouse and PIM plugins (PR-842–843) need a shared outbound client instead of each plugin reimplementing `net/http` wiring, timeouts, and GraphQL envelopes.

## Scope

- `pkg/integrationsdk/doc.go` — package overview + `Logger` interface
- `pkg/integrationsdk/http/client.go` — REST client (`Do`, `DoJSON`, `Get`, `Post`)
- `pkg/integrationsdk/graphql/client.go` — GraphQL POST client (`Query`)
- Unit tests with `httptest.Server` (success, HTTP errors, GraphQL errors, timeout, body limit)

## Out Of Scope

- Reference warehouse/PIM plugins (PR-842–843)
- OAuth/token refresh helpers (plugins supply headers from config)
- Retry logic (sync jobs + queue port handle retries)

## HTTP client

```go
client, err := sdkhttp.New(sdkhttp.Config{
    BaseURL: "https://warehouse.example.com",
    Timeout: 30 * time.Second,
    Headers: map[string]string{"Authorization": "Bearer " + token},
    Logger:  app.Logger, // optional; implements integrationsdk.Logger
})
resp, err := client.Get(ctx, "/stock", nil)
err = client.DoJSON(ctx, http.MethodPost, "/items", nil, reqBody, &out)
```

Defaults: 30s timeout, 1 MiB max response body, redirects disabled.

Non-2xx responses from `DoJSON` return `*http.StatusError` with status and body bytes.

## GraphQL client

```go
gql, err := sdkgraphql.New(sdkgraphql.Config{
    Endpoint: "https://pim.example.com/graphql",
    Headers:  map[string]string{"Authorization": "Bearer " + token},
})
var data struct { Product struct { Name string `json:"name"` } `json:"product"` }
err = gql.Query(ctx, `query ($slug: String!) { product(slug: $slug) { name } }`,
    map[string]interface{}{"slug": slug}, &data)
```

GraphQL `errors` array returns `*graphql.Error` with problem messages.

## Validation

- `go test ./pkg/integrationsdk/...`
- `go build ./cmd/api/`
- HTTP GET/POST against test server succeeds with default headers
- Timeout and oversized response bodies fail predictably
- GraphQL data decoded; GraphQL errors surfaced

## What changed

- Outbound integration plugins can call warehouse REST and PIM GraphQL through a shared, stdlib-first client layer
