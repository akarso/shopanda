# PR-853 — Reference Port Replacement

Status: done

## Summary

- Ship `plugins/taxdemo` reference plugin demonstrating tax port + pipeline replacement
- `RegisterTaxCalculator` with a config-driven flat-rate calculator
- `RegisterPricingStep(..., replace:tax)` occupies the core tax slot (PR-852)
- Opt-in via `plugins.taxdemo` config and compile-time registration

## Why

PR-813 shipped the tax calculator port and PR-852 added replace-by-name pricing steps. Integrators still need a copy-paste template showing both patterns together without forking `main.go` or `TaxStep`.

## Scope

- `plugins/taxdemo/` — plugin, flat-rate calculator, tax step, README
- `internal/platform/config` — `plugins.taxdemo` config + env vars
- `cmd/api/register_plugins.go` — opt-in registration when enabled
- Unit tests (calculator, registration, merged pipeline)

## Out Of Scope

- Production tax engine / ERP integration
- Config driver switch for tax (single registration winner unchanged)
- Admin tax UI changes

## Plugin behavior

| Mechanism | Registration | Default |
| --- | --- | --- |
| Tax calculator port | `RegisterTaxCalculator` | Flat 19% (`flat_rate_bps: 1900`) |
| Pricing pipeline slot | `replace:tax` → `taxdemo.flat_tax` | Uses same calculator |

Enable:

```yaml
plugins:
  taxdemo:
    enabled: true
    flat_rate_bps: 1900
```

Uses standard `PricingContext.Meta` keys: `tax_country`, `tax_mode`.

## Validation

- `go test ./plugins/taxdemo/...`
- `go build -o /tmp/shopanda-api ./cmd/api/`
- Plugin enabled → `plugins report` lists tax port as active and pricing step `replace:tax`
- Plugin disabled → `Init` returns error (not loaded)

## What changed

- Reference tax replacement plugin wired via compile-time registration
- Demonstrates Phase 8 integrator acceptance: infrastructure port replacement + replace-by-name pricing step
