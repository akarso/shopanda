# PR-820 — Import Row Hook Registry

Status: done

## Summary

- Add `importctx` application registry with ordered row hook chains per entity
- Expose `app.Import().RegisterRowHook(entity, priority, fn)` to plugins during `Init`
- Publish stable `pkg/extapi` import entity constants and hook catalog
- Wire shared registry at API startup (`SetImportRegistry`)

## Why

Integrators need to remap ERP CSV columns before persistence without forking `internal/application/importer`. Track C starts with the registration seam; core importers invoke the chain in PR-821.

## Scope

- `internal/application/importctx/` — entities, `RowContext`, registry (`Register`, `Invoke`, `Catalog`)
- `pkg/extapi/import.go` — `ImportEntity`, `ImportRowContext`, `ImportRowHandler`, `RowHookPoint`
- `internal/platform/plugin/import.go` — plugin bridge with extapi payload sync
- `cmd/api/main.go` — shared `importRegistry` + `SetImportRegistry`
- Unit tests (importctx, plugin bridge, extapi parity)

## Out Of Scope

- Wiring CLI importers to invoke the chain (PR-821)
- `Skip` flag and aggregated `ImportResult` errors (PR-822)
- Reference CSV remap plugin (PR-823)

## API

**Entities:** `product`, `price`, `stock`, `category`, `customer`, `attribute`

**Hook names:** `import.{entity}.row` (e.g. `import.product.row`)

```go
app.Import("acme/erp").RegisterRowHook(extapi.ImportEntityProduct, 100, func(ctx *extapi.ImportRowContext) error {
    ctx.Row["sku"] = ctx.Row["MATNR"]
    return nil
})
```

Handlers run in priority order (lower first). First handler error stops the chain. Panics are recovered and returned as errors.

## Validation

- `go test ./internal/application/importctx/... ./internal/platform/plugin/... ./pkg/extapi/...`
- `go build ./cmd/api/`
- Plugin `Init` can register row hooks; `ImportRegistry().Invoke` mutates row map
- `extapi.ImportEntities()` and `extapi.ImportRowHookCatalog()` match internal catalog

## What changed

- Import row hook registry is registered and callable; importers do not invoke it yet
- Plugins receive mutable `Row` / `Meta` maps via extapi bridge (empty rows start with allocated maps)
