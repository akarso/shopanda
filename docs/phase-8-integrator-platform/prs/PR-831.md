# PR-831 — Integration Auth Middleware

Status: done

## Summary

- Ship API-key auth middleware for inbound integration routes
- Optional HMAC-SHA256 signature verification with timestamp freshness + replay protection
- Add `RegisterSecureRoute` plugin facade and `ReplayStore` port (in-memory default)

## Why

PR-830 defined route conventions and error envelopes; ERP inbound endpoints need documented authentication before idempotency (PR-832) and the reference plugin (PR-833).

## Scope

- `pkg/extapi/integration_auth.go` — auth header names and error codes
- `pkg/integrationhttp/auth.go` — `AuthConfig`, `SecureHandler`, canonical HMAC payload, `SignRequest` helper
- `pkg/integrationhttp/replay.go` — `ReplayStore` + `MemoryReplayStore`
- `internal/platform/plugin/integration.go` — `RegisterSecureRoute`
- Unit tests (auth, replay, secure route registration)

## Out Of Scope

- Postgres-backed replay store (production plugins can supply custom `ReplayStore`)
- Idempotency-Key dedupe (PR-832)
- Reference inbound order-status plugin (PR-833)

## Auth model

**API key (required):** header `X-Integration-Key` or `Authorization: Bearer <key>`

**HMAC (optional when `HMACSecret` set):**

| Header | Purpose |
| --- | --- |
| `X-Integration-Timestamp` | Unix seconds |
| `X-Integration-Nonce` | Unique per request |
| `X-Integration-Signature` | HMAC-SHA256 hex of canonical payload |

Canonical payload:

```text
METHOD\nPATH\nTIMESTAMP\nNONCE\nSHA256(body_hex)
```

Default freshness window: ±5 minutes. Replay store rejects repeated nonce/signature pairs within the window.

## Plugin API

```go
auth := integrationhttp.AuthConfig{
    APIKey:     cfg.IntegrationAPIKey,
    HMACSecret: cfg.IntegrationHMACSecret,
    ReplayStore: integrationhttp.NewMemoryReplayStore(),
}
app.Integration("acme").RegisterSecureRoute("POST", "order-status", auth, handler)
```

Recommended plugin config fields (via `RegisterConfig`):

- `plugins.{plugin}.integration_api_key` (secret)
- `plugins.{plugin}.integration_hmac_secret` (secret, optional)

## Validation

- `go test ./pkg/integrationhttp/... ./internal/platform/plugin/...`
- `go build ./cmd/api/`
- Valid API key passes; invalid key → `auth.invalid_key`
- HMAC signature validates body + headers; replay returns `auth.replay_detected`
- Expired timestamp → `auth.expired_timestamp`

## What changed

- Integrators secure inbound ERP routes with documented API-key and optional HMAC + replay middleware
