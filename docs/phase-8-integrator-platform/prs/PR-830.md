# PR-830 — Integration Route Conventions

Status: done

## Summary

- Publish integration route prefix helpers on stable `pkg/extapi`
- Add `app.Integration(slug).RegisterRoute` / `RegisterAdminRoute` plugin facades
- Ship `pkg/integrationhttp` structured error envelope and JSON helpers

## Why

Track D starts with documented inbound ERP REST conventions. Integrators need a namespaced route prefix and ERP-parseable errors before auth/idempotency middleware (PR-831–832) and the reference plugin (PR-833).

## Scope

- `pkg/extapi/integration.go` — route prefix/pattern builders, `IntegrationErrorResponse`, slug validation
- `pkg/integrationhttp/response.go` — `WriteError`, `WriteJSON`, `DecodeJSON`
- `internal/platform/plugin/integration.go` — `Integration` facade wiring to public/admin route registries
- Unit tests (extapi, integrationhttp, plugin)

## Out Of Scope

- API-key / HMAC auth middleware (PR-831)
- Idempotency store (PR-832)
- Reference SAP-style inbound plugin (PR-833)

## Conventions

**Public routes:** `/api/v1/integrations/{plugin}/…`

**Admin routes:** `/api/v1/admin/integrations/{plugin}/…`

**Plugin slug:** lowercase letters, digits, `-`, `_`; no `/`.

**Error envelope:**

```json
{
  "error": "invalid_payload",
  "message": "missing order_id",
  "details": { "field": "order_id" }
}
```

## Plugin API

```go
app.Integration("acme").RegisterRoute("POST", "order-status", handler)
app.Integration("acme").RegisterAdminRoute("GET", "health", perm, handler)

integrationhttp.WriteError(w, http.StatusBadRequest, "invalid_payload", "missing order_id", details)
integrationhttp.WriteJSON(w, http.StatusOK, payload)
```

Patterns resolve to e.g. `POST /api/v1/integrations/acme/order-status`.

## Validation

- `go test ./pkg/extapi/... ./pkg/integrationhttp/... ./internal/platform/plugin/...`
- `go build ./cmd/api/`
- Invalid slug or path traversal rejected at registration
- `WriteError` emits documented JSON shape

## What changed

- Integrators register namespaced inbound routes and return structured ERP-parseable errors without patching `cmd/api/main.go`
