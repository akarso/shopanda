# PR-801 — Port Catalog + Introspection Endpoint

Status: done

## Summary

- Canonical infrastructure **port catalog** in `internal/application/ports`
- **Runtime snapshot** builder from plugin registration + config
- Admin API `GET /api/v1/admin/extensions/ports` (requires `extensions.read`)

## Why

Integrators need to see which infrastructure backends are active (search, cache, queue, payment, media) and which ports are planned (tax, mail, …) without reading `register_plugins.go` or startup logs.

## Scope

- `internal/application/ports/catalog.go` — documented port list aligned with [INTEGRATOR_PLATFORM.md](../specs/INTEGRATOR_PLATFORM.md) §3
- `internal/application/ports/snapshot.go` — `BuildSnapshot(plugin.App, config.Config)`
- `internal/interfaces/http/extension_port_admin.go` — read-only admin handler
- `cmd/api/main.go` — route wiring after plugin init
- Unit tests for snapshot builder and HTTP handler

## Out Of Scope

- CLI `plugins report` (PR-851)
- Behavioral pipeline introspection (pricing steps, hooks)
- New port implementations (tax calculator — PR-813)
- Admin SPA UI for ports list

## Validation

- `go test ./internal/application/ports/... ./internal/interfaces/http/... -run 'TestBuildSnapshot|TestCatalog|TestExtensionPort'`
- `go build ./cmd/api/`
- `GET /api/v1/admin/extensions/ports` returns shipped ports with `active` / `core_default` / `unconfigured` and planned ports with `planned`
- Payment port lists registered methods when registry is populated

## API shape

```json
{
  "data": {
    "ports": [
      {
        "name": "search",
        "register_api": "RegisterSearchProvider",
        "config_key": "search.engine",
        "status": "core_default",
        "source": "core",
        "driver": "postgres",
        "implementation": "postgres.SearchEngine",
        "notes": "Product search backend (postgres, meilisearch)"
      }
    ]
  }
}
```

Payment port may include `providers[]` with per-method implementation and source.

## What changed

- Port catalog + snapshot application package
- Admin introspection endpoint alongside existing hooks/slots catalog routes
