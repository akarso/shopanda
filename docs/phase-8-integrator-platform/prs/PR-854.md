# PR-854 — Checkout Step Positioning

Status: done

## Summary

- `RegisterCheckoutStep(step, position...)` — optional `start`, `end`, `before:<step>`, `after:<step>` positions
- Canonical core checkout step catalog + aliases (`order` → `create_order`, `payment` → `initiate_payment`, …)
- `MergePluginSteps` wires plugin steps into the core checkout workflow at startup
- Stable v0 constants in `pkg/extapi` and `pluginsdk` checkout helpers

## Why

CHECKOUT_WORKFLOW.md documented anchor positions since Phase 1, but registration stayed append-only. Integrators need validation or side effects before `create_order` or after `validate_cart` without forking `main.go`.

## Scope

- `internal/application/checkout/position.go` — parse, merge, `CoreStepCatalog`
- `internal/platform/plugin/checkout_steps.go` — positioned registration + `CheckoutStepRegistrations()`
- `cmd/api/main.go` — build core workflow then merge plugin steps
- `pkg/extapi/checkout.go` — stable step names for plugin authors
- `pkg/pluginsdk/checkout.go` — typed checkout position helpers
- `internal/application/pluginreport` — core + plugin checkout steps with positions
- Unit tests for merge, registration, extapi, pluginsdk

## Out Of Scope

- Replace-by-name checkout steps (pricing-only today)
- Reference checkout plugin (stretch; cartdemo covers related patterns)
- Admin merged workflow preview with live core step instances

## API

```go
// Default: end (same as omitting position — legacy append-only behavior)
app.RegisterCheckoutStep(myStep{})

// Before order creation
app.RegisterCheckoutStep(myStep{}, extapi.BeforeCheckoutStep("create_order"))
sdk.Checkout().Register(myStep{}, pluginsdk.CheckoutBefore("order"))

// First step in workflow
sdk.Checkout().Register(preflightStep{}, pluginsdk.CheckoutStart())
```

### Core step catalog (stable v0)

| Name | Step |
| --- | --- |
| `validate_cart` | Cart validation |
| `recalculate_pricing` | Pricing pipeline |
| `reserve_inventory` | Stock reservation |
| `create_order` | Order persistence |
| `select_shipping` | Shipping selection |
| `initiate_payment` | Payment initiation |

Aliases: `validate`, `pricing`, `inventory`, `order`, `shipping`, `payment`. Shortcuts: `start`, `end`.

Invalid positions panic at registration (fail fast at startup).
