# PR-833 — Reference Plugin: Order Status Inbound

Status: done

## Summary

- Ship `plugins/integrationdemo` reference plugin for inbound ERP order status callbacks
- Accept flat JSON or simplified SAP `E1ORDSTAT` payload on `RegisterSecureRoute`
- Wire `extapi.IntegrationOrderStatusUpdater` port + `order.StatusService` for domain-valid transitions

## Why

Track D (PR-830–832) shipped route conventions, auth, and idempotency middleware. Integrators need a copy-paste reference showing a thin handler calling core order services without importing Postgres from `plugins/*`.

## Scope

- `pkg/extapi/integration_order.go` — order status updater port + error codes
- `internal/application/order/status_service.go` — shared status transition service
- `internal/platform/plugin/integration_order.go` — `SetIntegrationOrderStatusUpdater`
- `internal/platform/plugin/integration_order_adapter.go` — ERP status normalization
- `plugins/integrationdemo/` — plugin, handler, payload parser, README
- `internal/platform/config` — `plugins.integrationdemo` config + env vars
- `cmd/api/register_plugins.go` + `cmd/api/main.go` — opt-in registration and wiring
- Refactor admin order status handler to reuse `ApplyStatusTransition`
- Unit + plugin HTTP tests (auth, idempotency replay, IDoc payload)

## Out Of Scope

- Production SAP IDoc parser or connector certification
- Admin UI for integration callbacks
- Outbound sync jobs (Track E)

## Plugin behavior

| Concern | Implementation |
| --- | --- |
| Route | `POST /api/v1/integrations/integrationdemo/order-status` |
| Auth | API key required; optional HMAC when `integration_hmac_secret` set |
| Idempotency | Automatic via `RegisterSecureRoute` when store is wired |
| Business logic | `IntegrationOrderStatusUpdater.ApplyOrderStatus` |

Enable:

```yaml
plugins:
  integrationdemo:
    enabled: true
    integration_api_key: change-me
    integration_hmac_secret: optional-hmac-secret
```

## Validation

- `go test ./plugins/integrationdemo/... ./internal/application/order/... ./internal/platform/plugin/...`
- `go build ./cmd/api/`
- Valid payload + API key → 202/200 with `order_status` body
- Same `Idempotency-Key` retry replays stored response
- Unknown order → `order.not_found`
- Invalid transition → `order.invalid_transition`
