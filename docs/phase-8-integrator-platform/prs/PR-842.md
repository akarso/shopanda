# PR-842 — Reference Plugin: Warehouse Stock

Status: done

## Summary

- Ship `plugins/warehousedemo` reference plugin for outbound warehouse stock sync
- Pull absolute stock levels from mock REST `GET /stock` via `pkg/integrationsdk/http`
- Upsert via `extapi.IntegrationStockSyncer` + `inventory.StockSyncService` on cron sync job

## Why

Track E (PR-840–841) shipped sync job registration and outbound HTTP client bootstrap. Integrators need a copy-paste reference showing warehouse pull → application service without importing Postgres from `plugins/*`.

## Scope

- `pkg/extapi/integration_stock.go` — stock syncer port + result types
- `internal/application/inventory/stock_sync_service.go` — SKU lookup + absolute stock upsert
- `internal/platform/plugin/integration_stock.go` — `SetIntegrationStockSyncer`
- `plugins/warehousedemo/` — plugin, sync handler, README, tests
- `internal/platform/config` — `plugins.warehousedemo` config + env vars
- `cmd/api/register_plugins.go` + `cmd/api/main.go` + `integration_wiring.go` — opt-in registration and wiring

## Out Of Scope

- Production WMS connector or multi-warehouse routing
- Delta/reservation-aware stock (absolute set only)
- PIM GraphQL enrichment (PR-843)

## Plugin behavior

| Concern | Implementation |
| --- | --- |
| Job | `integration.sync.warehousedemo.warehouse.stock` |
| Trigger | Cron (default `@every 5m`) |
| HTTP | `GET {warehouse_base_url}/stock` with optional Bearer token |
| Business logic | `IntegrationStockSyncer.UpsertBySKU` |

Enable:

```yaml
plugins:
  warehousedemo:
    enabled: true
    warehouse_base_url: "http://localhost:9090"
    warehouse_api_key: optional-bearer-token
    sync_cron: "@every 5m"
```
