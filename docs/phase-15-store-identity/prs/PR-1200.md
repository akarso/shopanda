# PR-1200 — Identity domain

Status: done

## Summary

- Add `Identity`, `Address` (four Magento-like roles), and `TaxIdentifier` in `internal/domain/store`.
- Constructors validate role, ASCII ISO-2 country, optional contact emails (mailbox-only after RFC 5322 parse), snake-token tax types, field length caps, and reject newlines on single-line fields.
- No postgres, no HTTP.

## Why

Store Information cannot be more config strings. Invoices and imprint need typed legal name, addresses, and tax IDs.

## Scope

- Domain types + unit tests for normalize/validate.
- Address roles: `general`, `invoice`, `shipping_origin`, `returns` via unexported catalog + `AllAddressRoles`.
- Contact emails: general / sales / support stored as `addr.Address` (lowercased).
- `Address.IsEmpty` for role fallback (country-only ≡ empty).

## Out Of Scope

- Registry of tax ID types (PR-1201).
- Persistence and API (PR-1202).

## What changed

| Area | Change |
| --- | --- |
| `identity.go` | `Identity`, mailbox-only email normalize, length caps, newline reject on legal/phone |
| `address.go` | Roles catalog copy, `IsEmpty`, ASCII country via `NormalizeCountry`, length caps |
| `tax_identifier.go` | Snake-token type `^[a-z][a-z0-9_]*$`, length caps; value trim only |
| `store.go` | `NormalizeCountry` requires ASCII A–Z (same rule as order destination) |
| `FromDB` constructors | Return pointers (match `NewStoreFromDB`); no re-validation |

### Code review (applied)

| Severity | Finding | Fix |
| --- | --- | --- |
| Blocker | Email stored raw phrase after parse | Store `strings.ToLower(addr.Address)`; tests for display name / angle / quoted / comment |
| Major | Weak country (`12`, `A1`, `Å`) | ASCII A–Z check in `NormalizeCountry` |
| Major | No empty predicate for fallback | `Address.IsEmpty` (ignores country); note PR-1202 backfill copies `store.Country` |
| Major | No max lengths | Caps: email 254, lines/name/city/region/hours 255, phone/postcode/tax 64 |
| Major | Junk tax types | Snake-token regex + length |
| Major | Exported mutable `AddressRoles` | Unexported + `AllAddressRoles()` copy; parse scans slice |
| Major | Missing regression tests | Phrase emails, bad countries, oversize, junk types, FromDB round-trip |
| Minor | FromDB value vs pointer | Pointers |
| Minor | Empty legal name / newlines | Empty legal OK (draft); reject newlines on legal + address lines |
| Major (r2) | U+2028 / VT / NUL still stored | `normalizeSingleLine` rejects C0 + NEL/LS/PS; tax value uses it |
| Major (r2) | Tax value `12\n34` accepted | Same single-line helper |
| Minor (r2) | Phone-only not empty; nil panics | Postal-only `IsEmpty`; nil receiver → empty |
| Minor (r2) | Huge display name / store id / role error | Cap raw email input; store-id single-line ≤64; sanitize role errors |
| Minor (r2) | Unexported caps | Exported `MaxEmailLen` / `MaxLegalNameLen` / … |
