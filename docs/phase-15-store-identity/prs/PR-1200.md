# PR-1200 — Identity domain

Status: done

## Summary

- Add `Identity`, `Address` (four Magento-like roles), and `TaxIdentifier` in `internal/domain/store`.
- Constructors validate role, ISO-2 country on addresses, optional contact emails (RFC 5322 when set), and non-empty type/value on tax IDs.
- No postgres, no HTTP.

## Why

Store Information cannot be more config strings. Invoices and imprint need typed legal name, addresses, and tax IDs.

## Scope

- Domain types + unit tests for normalize/validate.
- Address roles: `general`, `invoice`, `shipping_origin`, `returns`.
- Contact emails: general / sales / support (format check only when non-empty).

## Out Of Scope

- Registry of tax ID types (PR-1201).
- Persistence and API (PR-1202).
