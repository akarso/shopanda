# PR-1213 — Admin email-template API

Status: done

## Summary

- List / get / put / delete / preview / test-send under `/api/v1/admin/email-templates`.
- Preview renders with a fixed sample payload (no SMTP). Test-send uses the resolved mailer synchronously.
- RBAC: `content.read` / `content.write`. Writes only for overridable names (PR-1212 allowlist).

## Why

UI needs a contract. Preview must not send.

## Scope

- Admin routes + Content RBAC.
- Raw subject/body retained on `mail.Templates` (`builtin` / `file` origin) for GET without a DB row.
- Revert (DELETE) removes DB row only.
- Tests: preview has no SMTP call; test-send does; PUT then GET returns body; auth/claim PUT rejected; `und` locale rejected.

## Out Of Scope

- Admin SPA (PR-1214).
- WYSIWYG.
- Unsaved-draft preview body in the request.
- Dedicated `email_templates.*` permissions.
