# PR-1205 — Invoice, email, storefront consumers

Status: done

## Summary

- Invoice PDF seller block: legal name, invoice address (fallback general), tax IDs (registry labels), phone, sales→general email.
- Notification `EmailData` filled from identity: `StoreName` = store DBA name, `StoreAddress` = formatted general, `LogoURL` from interim `store.logo`, existing `StoreURL`.
