# PR-1210 — Wire file email loader

Status: done

## Summary

- `cmd/` calls `email.LoadDir` after `RegisterTemplates` so `templates/emails/*.html` overwrite builtins.
- Render paths wrap bodies with `_layout.html` via `mail.Layout` (`notification.WithLayout`, cart recovery `Layout`).
- `EmailData` brand fields already filled from store identity (PR-1205); cart recovery uses `EmailBrandSource` (no `"Shopanda"` hardcode).
- Docker image ships `templates/emails/`; missing dir keeps builtins with a warn.

## Why

File templates and layout already existed. Production never loaded them.

## Scope

- Composition-root wiring (`loadFileEmailTemplates`) for serve + worker.
- Layout wrap on notification + cart recovery render.
- Dockerfile + DEPLOYMENT note for the templates tree.
- Tests: file wins over builtin; missing dir; layout wrap on `order.paid`.

## Out Of Scope

- New template files (PR-1211).
- DB override (PR-1212).
- Guest order-claim as a named file template (PR-1211).
