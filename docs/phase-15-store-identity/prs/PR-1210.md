# PR-1210 — Wire file email loader

Status: done

## Summary

- `cmd/` calls `email.LoadDir` after `RegisterTemplates` so `templates/emails/*.html` overwrite builtins.
- Render paths wrap bodies with `_layout.html` via `mail.ApplyLayout` (`notification.WithLayout`, cart recovery `Layout`).
- File parse errors return from `TryRegister` / `LoadDir` and fail boot (no panic on the main goroutine). `LoadDir` parses the whole directory before any registry write.
- Resolve relative dir from cwd, then `/app/templates/emails` (Docker). Empty cwd trees are misses. Log candidates, abs path, overwritten names, and `layout_loaded`.
- Cart recovery claims first, then enqueues with a stable job id (Conflict collapses Postgres/Redis retries). Non-conflict enqueue errors clear the claim only when `recovery_email_sent_at` still matches the mark timestamp (`ErrRecoveryClaimMismatch` on CAS miss). Failed Conflict uses invoice-style `ReplaceFailed` (fresh payload, attempts=0) and keeps the mark on success; `WrapRequeueNotify` forwards `ReplaceFailed`, and recovery also walks `UnwrapQueue` when the outer value lacks it. Queues without `ReplaceFailed` (Redis) keep the mark. Cancelled and reclaiming keep the mark (no revive). Pending/processing/done keep the mark. Redis implements `Get` so failed conflicts are visible (brokers without Get keep the mark).
- `EmailData` brand fields from store identity (PR-1205); `StoreURL` trimmed; layout omits empty-address dash and bounds the logo.
- Docker image ships `templates/emails/`; missing dir keeps builtins with a warn.

## Why

File templates and layout already existed. Production never loaded them.

## Scope

- Composition-root wiring (`loadFileEmailTemplates`) for serve + worker.
- Safe file register + layout wrap on notification + cart recovery.
- Dockerfile + DEPLOYMENT note for the templates tree.
- Tests: file wins; parse fail; repo tree render; layout wrap / wrap-error skip enqueue.

## Out Of Scope

- New template files (PR-1211).
- DB override (PR-1212).
- Guest order-claim as a named file template (PR-1211).
- Reordering cart recovery mark-before-render (still marks before wrap).
