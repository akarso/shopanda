# PR-1214 — Admin email-template editor

Status: done

## Summary

- Content → Email Templates: list, edit subject/HTML, preview, test send, revert.
- Link Abandoned Cart settings to the `cart_recovery` editor (no fake template picker).

## Why

Phase 6 backlog “template editor with preview.” Merchants should not SSH to change “Thank you for your order.”

## Scope

- Nav item under Content (`/admin/content/email-templates`).
- Textarea editor only (vanilla admin SPA).
- Uses PR-1213 API (`content.read` / `content.write`).
- Read-only templates remain openable for view/preview; Save/Revert/Test send hidden when `writable` is false.
- Preview shows live render metadata (`source` / `resolved_locale` / `fallback`) in a sandboxed iframe.
- Scoped editor session: separate locale/preview/write gates; queries use the captured editor root (`isConnected`); PUT/DELETE lock the form.

## Out Of Scope

- Visual builder, A/B, marketing mail.
- Unsaved-draft preview (preview uses saved/live render chain).
- C4 / config / RUNBOOK — no change (SPA-only).
