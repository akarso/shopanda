# PR-1202 — Persistence + admin/public API

Status: planned

## Summary

- Migration for identity, addresses, tax identifier values.
- Postgres repo + application service.
- Admin REST per [`STORE_IDENTITY.md`](../specs/STORE_IDENTITY.md) §4.
- Public `GET /api/v1/store/identity`.
- Backfill `store.address` → `general.line1`.

## Why

Merchants and storefronts need a single read/write path. Headless cannot scrape admin config keys.

## Scope

- Store-scoped CRUD; unique `(store_id, address.role)`, `(store_id, tax type)`.
- Empty address roles returned as placeholders on list.
- Invoice address fallback is a read helper (invoice → general), not a silent write.
- RBAC aligned with store/config update.
- Tests: backfill, fallback, unknown role 422, public GET has no SMTP secrets.

## Out Of Scope

- Admin SPA pages (PR-1203–1204).
- Invoice PDF / email / footer consume (PR-1205).
