# PR-1201 — Tax identifier type registry

Status: done

## Summary

- In-process registry of tax/company identifier types with `Code`, `Label`, `Countries`, `Region`, `FormatHint`.
- Core catalog from [`STORE_IDENTITY.md`](../specs/STORE_IDENTITY.md) §3.1.
- Plugin port `RegisterTaxIdentifierType` on `plugin.App` and `pluginsdk.Host`; duplicate codes fail closed.

## Why

NIP vs VAT vs EIN is country-dependent. Core must not grow a column per country. Plugins extend the catalog.

## Scope

- Registry + core seed list.
- Query: all types; `ApplicableTo` = Countries contains store country, then `generic` last (`Region` is UI grouping only).
- Wire register on `plugin.App` / `pluginsdk.Host`; freeze after `InitAll`.
- Unit tests: exact applicable sets (PL/DE/FR/GB/US/unknown); Host validate + duplicate `pl_nip`; `Get("PL_NIP")`.

## Out Of Scope

- Checksum validators.
- Persistence of identifier *values* (PR-1202).
- Admin UI.
