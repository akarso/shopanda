# PR-1201 — Tax identifier type registry

Status: planned

## Summary

- In-process registry of tax/company identifier types with `Code`, `Label`, `Countries`, `Region`, `FormatHint`.
- Core catalog from [`STORE_IDENTITY.md`](../specs/STORE_IDENTITY.md) §3.1.
- Plugin port `RegisterTaxIdentifierType`; duplicate codes fail closed at registration.

## Why

NIP vs VAT vs EIN is country-dependent. Core must not grow a column per country. Plugins extend the catalog.

## Scope

- Registry + core seed list.
- Query: all types; types applicable to a country (country match, region match, plus `generic`).
- Wire register on `plugin.App` (or existing register surface).
- Unit tests: PL sees `pl_nip` + `eu_vat`; US sees `us_ein`; unknown country still gets `generic`.

## Out Of Scope

- Checksum validators.
- Persistence of identifier *values* (PR-1202).
- Admin UI.

## Follow-up

- PR-1202 — store values + APIs.
