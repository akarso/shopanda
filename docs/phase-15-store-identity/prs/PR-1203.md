# PR-1203 — Store Information admin page

Status: done

## Summary

- Settings → Store Information (`/admin/settings/store-information`).
- Form: legal name, phone, hours, general / sales / support emails via PR-1202 identity API.
- Second card: tax identifiers (country-filtered types + Add other).
- Removed address textarea and logo URL from Settings → General (logo waits for PR-1222; address waits for PR-1204). Existing config values remain served until those pages ship.
- CR: page + tax-panel load gates (panel `start()` before tax list GET), write settlement by store id (language/currency does not remount this page), attribute-safe identity/General fill via DOM `.value`, per-card refresh that awaits type-list paint, independent identity/tax failure domains, tax upsert replace confirm, store-scoped banner (including unknown store id), exact `/admin/settings` sidebar match, node tests for slow earlier list GET vs newer refresh.

## Why

Magento-like dedicated page. Settings → General is SMTP + media, not legal identity.

## Scope

- Sidebar item under Settings (no placeholder).
- Load/save via PR-1202 identity API; requires store scope in the header switcher.
- Store name/code/domain/country/locale/currency stay on Settings → General store form.
- Tax identifiers card: applicable types for store country + Add other; upsert/delete.

## Out Of Scope

- Address role pages (PR-1204).
- Site Identity / logo UI (PR-1222).
