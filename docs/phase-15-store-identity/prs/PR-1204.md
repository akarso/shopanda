# PR-1204 — Address pages

Status: planned

## Summary

- Settings → Store Addresses (`/admin/settings/store-addresses`): four role cards (general, invoice, shipping origin, returns).
- Per-role page with structured fields: line1, line2, city, region, postcode, country, optional phone.
- Magento-like: one page per address role, not one textarea.

## Why

Warehouse origin, invoice legal seat, and returns address are different places. A blob cannot express that.

## Scope

- Index + `{role}` form; save via PR-1202.
- Show fallback hint when invoice/returns are empty (“will use general”).
- Country default = store country.

## Out Of Scope

- Shipping calculator reading `shipping_origin` (follow-up; data is stored).
- Customer address book (already exists, unrelated).
