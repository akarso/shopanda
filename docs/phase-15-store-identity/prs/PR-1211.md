# PR-1211 — Remaining file templates

Status: done

## Summary

- Add HTML files for every remaining `RegisterTemplates` name plus guest order-claim.
- Convert claim mail in `cmd/api` to the named `order_claim` template with `_layout.html` wrap and identity brand fields.
- Claim mail includes a copy-pasteable URL, expiry copy, and `text/plain` alternative; uses `resolveMailer` + request context timeout.
- Cart recovery formats major-unit unit/line prices and requires an absolute store URL.

## Why

Verification / recovery / claim still bypassed the layout and the upcoming editor.

## Scope

- Files under `templates/emails/` listed in [`EMAIL_TEMPLATES_ADMIN.md`](../specs/EMAIL_TEMPLATES_ADMIN.md) §2.
- Builtin `order_claim` fallback in `RegisterTemplates`.
- Same `EmailData` + layout as PR-1210 for claim sends.
- Tests: each name loads from the repo tree; claim path renders `order_claim`.

## Out Of Scope

- Admin editor.
- Copy polish beyond matching current builtin meaning.
- `voucher_issued` file (stays builtin until a later PR if needed).
