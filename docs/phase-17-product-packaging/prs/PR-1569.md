# PR-1569 — Plugins Extra nested map flatten + env aliases

Status: done

## Summary

`PluginsConfig.Extra` flattens nested YAML maps to dotted keys
(`generation.provider`), rejects lists, and keeps `.` / `_` aliases in sync
so `SHOPANDA_PLUGINS_<SLUG>_GENERATION_PROVIDER` overrides YAML. Both forms
are stored as exact keys (Host lookup is exact). Conflicting alias values
fail Load (YAML and env↔env). Env still overrides YAML when aliases agree.
Secret redaction treats dotted aliases like underscore forms
(`api.key` → `***` in `Get`).

## Scope

- Recursive flatten; list → error; alias conflict → error (YAML + env)
- `looksSecretPluginKey` normalises `.`→`_` before matching
- Tests: nesting, env override, list, secret alias redaction, conflicts,
  three-level keys, env alias conflict
- config.example.yaml + PRODUCT_SITES note
- ROADMAP follow-up → done

## Out of scope

- Removing typed MetalDogs / demo fields
- Deep env slug parsing for slugs that contain underscores
- No C4 change — config map only
