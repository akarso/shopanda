# PR-1590 — Per-command CapCatalogSeed CLI Needs

Status: done

## Summary

Plugin-level `Need(CapCatalogSeed)` blocked every `RequiresDB: false` command of
that plugin (`metaldogs:eval`). Add `CLICommand.Needs` and only refuse when the
**command** lists CapCatalogSeed without RequiresDB; sibling non-DB commands run.

- `pluginsdk.CLICommand.Needs` / `cli.Command.Needs`
- Bind CapCatalogSeed from command Needs, or (compat) plugin-level Need when
  command Needs is empty and RequiresDB
- Test: one plugin, seed + eval through `runPluginCLICommand`

- `cmd/api/cli_plugins.go` + tests
- PLUGINS.md / ROADMAP
