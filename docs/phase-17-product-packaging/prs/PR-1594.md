# PR-1594 — Plugin CLI skips CapJobs / CapMedia

Status: done

## Summary

Plugins that `Require(CapJobs)` / `Require(CapMedia)` for serve/worker failed
every `runPluginCLICommand` RequiresDB path: `pluginCLINeedsSkip` did not skip
those caps while the CLI never binds Jobs/Media.

- Add `CapJobs` + `CapMedia` to `pluginCLINeedsSkip`
- Test: Require both; RequiresDB + non-DB commands run; `Host.Jobs()` /
  `Host.Media()` stay `(nil, false)`

## Scope

- `cmd/api/plugin_boot.go` + `cli_plugins_test.go`
- EXTENSION_POINTS / AGENTS / ROADMAP

## Out of scope

- Binding CapJobs/CapMedia on plugin CLI via `CLICommand.Needs`
- WithJobID requeue race (PR-1595)
- No C4 change

## Validation

```bash
go test ./cmd/api/ -count=1 -run 'RunPluginCLICommand_CapJobsMediaSkipped|RunPluginCLICommand_'
```
