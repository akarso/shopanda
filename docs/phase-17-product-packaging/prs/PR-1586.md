# PR-1586 — harness.OpenIsolated test DB

Status: done

## Summary

Plugin integration tests needed an isolated Postgres schema with pinned
`search_path`, core + plugin migrations, and cleanup — previously copied as
`testutil.OpenIsolated` importing `internal/platform/migrate`. Add
`pkg/pluginsdk/harness.OpenIsolated` and wire `AdaptInit` `Options.DB` for
`Host.BootstrapDB()`.

- Skips when `SHOPANDA_TEST_DSN` is unset
- Creates schema, pins `search_path` on every connection, drops on cleanup
- Core `migrate.Run` (auto-discover or `CoreMigrationsDir`; `"-"` skips)
- Optional `pluginsdk.ApplyMigrationFS` for plugin SQL
