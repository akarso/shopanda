# PR-1567 — CatalogSeedPort EnsurePrice Update mode

Status: done

## Summary

`EnsurePrice` stays create-only by default. `CatalogPriceSeed.Update`
opts into amount changes with a price-history snapshot in the same
transaction (standalone Ensure or Import). Same amount is a no-op;
missing rows still create.

Also verified/documented: empty `Status` on an existing `active` product
is a soft no-op; Attributes remain create-only (subset match cannot add
keys on re-seed — Metal Dogs must seed attrs on first create or use admin).

## Scope

- `CatalogPriceSeed.Update bool`
- Adapter: create-only vs update path; preserve price id; history with Upsert
- Unit tests: create-only hit, same-amount Update, amount change, Import Update
- Empty-Status-on-active soft success test
- EXTENSION_POINTS + ROADMAP follow-up → done

## Out of scope

- Updating product/variant Status/Type/Attributes in place
- Attribute registry / adding keys on existing rows
- No C4 change — seed DTO flag only
