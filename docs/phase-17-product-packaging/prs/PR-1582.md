# PR-1582 — `pluginsdk.RequestIDFromContext`

Status: done

## Summary

Plugins that correlate logs with the HTTP / sync-job request id had to import
`internal/platform/requestctx`. Expose a public read accessor on `pluginsdk`
so product plugins stay on `pkg/*`.

- `pluginsdk.RequestIDFromContext(ctx)` wraps `requestctx.RequestID(ctx)`.
- No public `WithRequestID` / `InjectRequestID` — stamp and sync reinjection
  stay platform-side (PR-1559).
