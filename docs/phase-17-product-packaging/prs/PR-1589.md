# PR-1589 — `pluginsdk.MigrationSpec` aliases `plugin.MigrationSpec`

Status: done

## Summary

A `plugin.App` plugin that implemented only `pluginsdk.Migrator` was silently
skipped by `CollectMigrations` (different named return type). Alias
`pluginsdk.MigrationSpec` to `plugin.MigrationSpec` so the method sets match
and Adapt is not required for collection/apply.

## Scope

- `pkg/pluginsdk/migrator.go` + `adapt.go` + test
- ROADMAP row → done

## Out of scope

- CapCatalogSeed per-command CLI (PR-1590)
- No C4 change
