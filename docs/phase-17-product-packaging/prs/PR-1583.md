# PR-1583 — `extapi.ParseMinorUnits` + `IsValidCurrency`

Status: done

## Summary

Plugins parsed human prices and validated currency codes with local copies of
core helpers. Add public `pkg/extapi` helpers so product plugins stay on `pkg/*`.

- `IsValidCurrency` — same `^[A-Z]{3}$` rule as `NewMoney`.
- `ParseMinorUnits(s, exponent)` — EU/US grouping and decimal separators;
  no rounding; rejects spaces, letters, signs, extra fraction digits, empty,
  and zero. Caller supplies the currency exponent (JPY 0, EUR 2, KWD 3).

- `pkg/extapi/money_parse.go` + tests

## Out of scope
