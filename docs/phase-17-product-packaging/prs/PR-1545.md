# PR-1545 — Service ports on Host

Status: done

## Summary

- Public `CartPort`, `CatalogPort`, `OrderPort` on `pluginsdk.Host` with minimal `extapi` read models.
- Adapters in `pkg/pluginsdk/port_adapt.go` wrap domain repos and `cart.Service`.
- `plugin.Bootstrap` adds `Products`, `Orders`, `Carts`; `newPluginBootstrap` populates them.

## Why

Product plugins need cart/catalog/order access without importing `internal/domain` or application services.

## Scope

- `pkg/pluginsdk`: `ports.go`, `port_adapt.go`, Host getters, tests.
- `pkg/extapi`: `CatalogProduct`, `CatalogVariant`, `OrderView`.
- `internal/platform/plugin`: expanded `Bootstrap`, `service_ports.go` (bind + getters).
- `cmd/api/plugin_bootstrap.go`, `wire_services.go` bootstrap fields.

## Out of scope

- Declarative Needs / unified wiring (PR-1546–1547).
- Hook extension visibility (PR-1548).
