# PR-1574 — Plugin CLI auto-binds CapCatalogSeed

Status: done

## Summary

`runPluginCLICommand` keeps the Init `*plugin.App` and, for `RequiresDB`
commands, opens the DB then binds product ports on that App. When any plugin
recorded `Need(CapCatalogSeed)`, it also calls `bindCatalogSeedPort` and
`AssertNeedsMetExcept(CapCart)`. Seed plugins use `pluginsdk.CLICommand` with
`RequiresDB: true` and resolve `Host.CatalogSeed()` in the command handler —
no product edit of `cli_plugins.go`.

## Scope

- `pluginCLIRuntime{Registry, App}`; `bindPluginCLIPorts` / `FromBoot`
- `pluginsdk.CLICommand.RequiresDB` + `CLIContext.DB`
- `App.CapabilityNeeded`
- Test: probe plugin Needs CapCatalogSeed → auto-bind → Host.CatalogSeed OK

## Out of scope

- Product-owned bind hook (auto-bind covers the acceptance test)
- Binding CapCatalogSeed on serve/worker
- No C4 change

## Validation

```bash
go test ./cmd/api/ -count=1 -run 'PluginCLI|BindPluginCLI|RunPluginCLI'
go test ./internal/platform/plugin/ -count=1 -run 'CapabilityNeeded'
go build -o /tmp/shopanda-api ./cmd/api/
```
