# PR-1579 — Invalid UUID requeue → ErrRequeueNotFound

Status: done

## Summary

Postgres `jobs.id` is a `uuid` column. `Queue.Requeue` / `RequeueWithBeforeCommit`
with a non-UUID id (e.g. `"missing-id"`) used to surface SQLSTATE `22P02`
(`invalid input syntax for type uuid`) instead of `jobs.ErrRequeueNotFound`.
That broke `TestJobQueue_Requeue_MissingID` against a real DSN and made
`jobs:requeue <not-a-uuid>` print a raw SQL error.

Reject non-UUID ids with `id.IsUUID` before `BeginTx`, and map any residual
`22P02` from the lock query to the same sentinel. Existing MissingID test
unchanged; add a no-DSN unit test for the early path.

## Scope

- `internal/infrastructure/postgres/job_queue.go` — parse check + 22P02 map
- Domain comment on `ErrRequeueNotFound`
- `TestJobQueue_Requeue_InvalidUUIDNoDB`
- RUNBOOK: not-found includes non-UUID id

## Out of scope

- Redis / broker requeue (string ids; missing already → `ErrRequeueNotFound`)
- Changing `Admin.Retry` / `Cancel` UUID handling
- No C4 change
