# PR-1558 — CatalogVariant.ProductVisible

Status: done

## Summary

Empty `ProductSlug` alone is ambiguous (missing parent, storefront scope,
blank slug column, nil products repo). Hooks that treat empty as “not my
product” fail open in `cart.validate`. `ProductVisible` is set when the
parent product was loaded under the current read scope; document
`WithOperatorProductReadScope` for background/admin contexts.
