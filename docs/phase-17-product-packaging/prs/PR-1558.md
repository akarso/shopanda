# PR-1558 — CatalogVariant.ProductVisible

Status: done

## Summary

Empty `ProductSlug` alone is ambiguous. `ProductVisible` means the parent
row was returned under status/read scope (not catalog/search/individually
axes). `extapi.BelongsToProductSlug` fail-closes when `!ProductVisible` or
the loaded slug is blank, and matches only on equal slug.

## Scope

- `CatalogVariant.ProductVisible` (parent row present under status scope)
- `extapi.BelongsToProductSlug` helper + tests (blank slug, missing parent)
- Docs corrected: axes are not part of this flag; operator scope for drafts

## Out of scope

- No C4 change — read-model field only
- Does not wire AllowProduct/facts into CatalogPort
- Does not add a separate “not visible” error from FindVariant
