# PR-1561 — RegisterPublicRoute NoCache

Status: done

## Summary

Plugin public routes inherited the default guest GET cache policy unless their
path matched a hardcoded denylist in `wire_routes.go`. Adds optional
`pluginsdk.NoCache()` / `plugin.WithNoCache()` on `RegisterPublicRoute` and
merges those path prefixes into `CacheControlMiddleware` at mount.

## Scope

- `PublicRoute.NoCache` + variadic options on App / Host
- `plugin.NoCachePathPrefixes` + wire_routes denylist merge
- Tests + PLUGINS / EXTENSION_POINTS note

## Out of scope

- Changing default cache policy for existing plugin routes
- No C4 change — HTTP middleware option only

## Validation

```bash
go test ./internal/platform/plugin/ ./internal/interfaces/http/shared/ ./pkg/pluginsdk/ -count=1 -run 'NoCache|PublicRoute|CacheControl'
go build -o /tmp/shopanda-api ./cmd/api/
```
