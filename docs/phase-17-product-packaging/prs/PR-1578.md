# PR-1578 — Fix WarehousedemoReachesBind media fixture

Status: done

## Summary

`TestNewJobsRuntime_WarehousedemoReachesBind` enabled `warehousedemo` with an
empty media config. `core/storage-local` still loads when `media.storage` is
empty and Init failed on empty `base_path`; the test logger was `io.Discard`,
so the failure looked opaque. Fixture now sets a temp `base_path` + `base_url`,
enables `SHOPANDA_DEV_MODE` for ephemeral sign secret, and dumps init logs on
failure.
