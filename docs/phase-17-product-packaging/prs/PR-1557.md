# PR-1557 — CartPort.DiscardEmptyGuestCart

Status: done

## Summary

Expose empty-guest discard on `CartPort` with an explicit cart id (the one
`EnsureStorefrontCart` returned). Conditional delete (guest, empty, version)
avoids wiping a cart that gained lines. Cookie is cleared only when that row
was deleted. `extref` design-line passes `cart.ID` after a failed first add.

- `CartPort.DiscardEmptyGuestCart(ctx, w, r, cartID)`
- `DeleteEmptyGuestIfUnchanged` uses `customer_id IS NULL` only (UUID column)
- Cookie cleared as soon as the row is deleted (even if orphan purge errors)
- Postgres + Ensure-then-fail tests; `extref` 5s detached timeout + Ensure id
- Docs: EXTENSION_POINTS / PLUGINS / AGENTS / ROADMAP → done
