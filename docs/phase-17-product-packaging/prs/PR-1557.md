# PR-1557 — CartPort.DiscardEmptyGuestCart

Status: done

## Summary

Expose the existing cart-service empty-guest discard on `CartPort` so plugin
public routes can clean up after a failed first `AddItem` (empty cart +
cookie). Clears the storefront cookie when a row is deleted. Signed-in
customers, missing cookies, and carts with items are no-ops.

## Scope

- `CartPort.DiscardEmptyGuestCart(ctx, w, r)`
- Service returns `(discarded bool, err)` so callers know when to clear cookie
- `extref` design-line calls discard on failed AddItem
- Docs: EXTENSION_POINTS / PLUGINS / AGENTS / ROADMAP → done

## Out of scope

- No C4 change — port method on existing CartPort
- Does not auto-discard inside `AddItem` (caller decides)
- Leaving an empty guest cart remains harmless (cookie Max-Age expiry)
