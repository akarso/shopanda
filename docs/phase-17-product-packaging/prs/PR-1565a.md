# PR-1565a — Attempt-aware Complete/Fail + ErrSkipOutcome

Status: done

## Summary

Job fence slice 1: `Queue.Complete` / `Fail` take the dequeue `attempt` so
stale deliveries cannot finish a newer claim (postgres CAS). Handlers may
return `jobs.ErrSkipOutcome` to skip platform outcome writes. Brokers accept
`attempt` best-effort without CAS in v1. Bind hooks / Requeue are PR-1565b.

## Scope

- `Complete(ctx, id, attempt)` / `Fail(ctx, id, attempt, err)`
- `jobs.ErrSkipOutcome` + worker skip path
- Postgres attempt CAS; redis/rabbit/kafka/sqs signature compatible
- Mock updates across test queues

## Out of scope

- `OnQueueBound` / `OnRequeued` / `Queue.Requeue` (PR-1565b)
- No C4 change — port signature only
