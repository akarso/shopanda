# PR-1565a — Attempt-aware Complete/Fail + ErrSkipOutcome

Status: done

## Summary

Job fence slice 1: `Queue.Complete` / `Fail` take the dequeue `attempt` so
stale deliveries cannot finish a newer claim. Zero-row updates return
`ErrOutcomeNotApplied` (worker never records success). Handlers may return
`jobs.ErrSkipOutcome` / `pluginsdk.ErrSkipOutcome` to skip platform outcome
writes (metric `skipped`). Brokers enforce attempt against inflight state.
Bind hooks / Requeue are PR-1565b.

## Scope

- `Complete(ctx, id, attempt)` / `Fail(ctx, id, attempt, err)`
- `ErrOutcomeNotApplied` + worker fail metrics (no success on miss)
- `jobs.ErrSkipOutcome` + `pluginsdk.ErrSkipOutcome` + skipped metric
- Postgres / Redis / Rabbit / Kafka / SQS attempt checks

## Out of scope

- `OnQueueBound` / `OnRequeued` / `Queue.Requeue` (PR-1565b)
- No C4 change — port signature only
