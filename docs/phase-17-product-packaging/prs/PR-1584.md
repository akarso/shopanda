# PR-1584 — CapJobs + Host.Jobs()

Status: done

## Summary

Plugins that read job state or requeue had to import `internal/domain/jobs`.
Add `CapJobs` and `Host.Jobs()` with Get / CountsByStatus / Requeue, and
re-export statuses, requeue options, and `ErrRequeue*` from `pkg/pluginsdk`.

- `plugin.CapJobs` + `BindJobsPort` / `JobsPort()`
- `pluginsdk.JobsPort`, `NewJobsPort`, status/option/error aliases
- `resolveAndBindJobQueue` binds CapJobs when the queue implements `jobs.Reader`
- Broker (Queue-only) leaves CapJobs unbound (Need fails closed)

## Scope

- `internal/platform/plugin/service_ports.go`
- `pkg/pluginsdk/{capability,host,apphost,jobs_port}.go` + tests
- `cmd/api/job_queue_bind.go` + bind_queue_test
- PLUGINS.md / DEVELOPER.md / AGENTS.md / ROADMAP

## Out of scope

- Enqueue/Dequeue/Complete/Fail / List on JobsPort
- CapMedia / harness / App symbol map
