# PR-1596 — Product-owned path convention

Status: done

## Summary

One convention for product files outside `plugins/<slug>/`:

- `docs/PRODUCT_OWNED.md` — owned vs hook manifest (machine-readable fence)
- Hooks: Make, docs-policy `product/checks/`, env/config fragments, compose
  override, `product/reserved-slugs.txt`, `.gitignore.product` markers + apply
  script
- `product-init` seeds `product/` when missing; must not dirty upstream roots
  (test)
- Deviation template points at the manifest instead of a per-product allowlist

## Scope

- Docs: PRODUCT_OWNED, PRODUCT_SITES, PLUGINS, UPSTREAM_DEVIATIONS, docs/README,
  DEVELOPER, ROADMAP
- Scripts: check-product-owned, apply-product-gitignore, docs-policy,
  product-init, product-init_test, seed copies
- Hook pointers in `.gitignore`, `.env.example`, `configs/config.example.yaml`,
  `docker-compose.yml`

## Out of scope

- Migrating Metal Dogs onto the convention
- `WithJobIDConflictOnly` / terminal keep policy (separate ROADMAP row)
- Shipping a filled `Makefile.product` / override compose upstream
- No C4 change
