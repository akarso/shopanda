# PR-1596 — Product-owned path convention

Status: done

## Summary

One convention for product files outside `plugins/<slug>/`:

- `docs/PRODUCT_OWNED.md` — owned / hook / companion manifest (tab-separated,
  machine-readable `expect` column drives `check-product-owned.sh`)
- Real hooks: Make `-include`, docs-policy `product/checks` (sorted), compose
  override, `product/reserved-slugs.txt`, `.gitignore` markers + harden
  `apply-product-gitignore.sh`
- Env/config siblings are **companions** (copy manually; no loader merge) — not
  sold as CI hooks
- `product-init` seeds `product/` when missing; test preserves pre-existing
  `product/` (trap restore; never `rm -rf` a real overlay)
- Platform CI fail-closed if `PRODUCT_OWNED.md` missing (fake trees opt out via
  `SHOPANDA_DOCS_POLICY_FAKE_TREE=1`)

## Scope

- Docs: PRODUCT_OWNED, PRODUCT_SITES, PLUGINS, UPSTREAM_DEVIATIONS,
  product-fork-upgrade, docs/README, DEVELOPER, ROADMAP
- Scripts: check-product-owned, apply-product-gitignore, product-owned_test,
  docs-policy, product-init, product-init_test, unit/Makefile wiring, seed
- `.gitignore` markers; companion comments on env/config examples; compose note

## Out of scope

- Migrating Metal Dogs onto the convention
- `.github/scripts/*` / `.cursor/rules/*` owned-or-hook rows (follow-up)
- Loader merge for env/config companions
- `WithJobIDConflictOnly` (separate ROADMAP row)
- No C4 change

## Notes

- `scripts/product-init/reserved-slugs.txt` gains `extref` via sync-seed catch-up
  (plugin already in-tree).
