# PR-1600 — OrderPort lines, extensions, and ListCreatedSince

Status: done

## Summary

Extend `pluginsdk.OrderPort` so product plugins can read order lines with
extension values and sweep orders created since a time — without SQL on core
tables. Line identity is `(order_id, variant_id)`.

## Scope

- `OrderPort.Lines` / `ListCreatedSince`; `extapi.OrderLineView` + `CreatedAt` on `OrderView`
- Domain `OrderRepository.ListCreatedSince` + Postgres keyset implementation
- Owner-scoped extension filtering (public + owned PluginOnlyWrite), via
  `AttachOrderLineExtensions` after ValueService (OrdersPort binds earlier)
- `Host.Orders()` `withOwner` (same pattern as Cart)
- AGENTS.md recipe; ROADMAP → done

## Out of scope

- Changing `order.created` publish order (PR-1601)
- `WithEventJobID` on RegisterOnEvent (PR-1602)
- No C4 change — same Orders port / repository components
