# PR-1580 — Context-aware media Read (localfs ReadContext)

Status: done

## Summary

`localfs.Storage.Read` used `os.ReadFile` with no context, so a cancelled
HTTP request or worker job kept reading large blobs. Metal Dogs wrapped
storage and patched core for `ReadContext`.

**Decision:** `media.ReadableStorage.Read` takes `context.Context` (same
shape as `SignedURLStorage.Head` / `SignedURL`). Localfs implements via
`ReadContext`: `ctx.Err()` before open and between 32 KiB chunks.
`Read` delegates to `ReadContext`. S3 grant delivery already uses
`Head`/`SignedURL` with ctx and does not implement `ReadableStorage`; no
S3 `Read` added.

Storefront download and admin invoice PDF pass `r.Context()`.

## Scope

- `media.ReadableStorage.Read(ctx, path)`
- `localfs.Read` / `ReadContext` + cancel + multi-chunk tests
- Call sites: download_account, invoice_admin (+ test fakes)
- Drive-by: `search_admin_test` fake `Requeue` used undefined `jobs` → `domainjobs` (admin package was not compiling on `dev`)
- C4 code diagram + DEVELOPER download flow note

## Out of scope

- S3 `ReadableStorage` / streaming Read
- Changing `Save` / `Delete` to take ctx
- Mid-chunk cancel injection harness (pre-cancelled ctx covers early exit)
