# PR-1597 — Checkout / API error details + unavailable 503

Status: done

## Summary

Plugin checkout steps (and any JSONError path) can return a stable client code,
a structured details payload (e.g. failing lines + retryable), and a deliberate
unavailable class that maps to HTTP 503 without being masked as internal 500.
