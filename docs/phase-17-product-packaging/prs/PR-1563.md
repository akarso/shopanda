# PR-1563 — Generic plugins.<slug> config map

Status: done

## Summary

Product plugins should not need a typed field on `PluginsConfig`. Unknown
YAML keys under `plugins:` land in `Extra`, flatten to `plugins.<slug>.*`,
and accept `SHOPANDA_PLUGINS_<SLUG>_<KEY>`. Host.Config* already reads the
flatten map. Typed demo / MetalDogs fields stay; MetalDogs marked migrate-next.

## Scope

- `PluginsConfig.Extra` + `UnmarshalYAML` for unknown slugs
- Flatten + env overlay (typed slugs skipped)
- config.example.yaml + PRODUCT_SITES / PLUGINS note

## Out of scope

- Deleting typed demo / MetalDogs fields
- Rewriting demos onto Extra
- No C4 change — config map only
