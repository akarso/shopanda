# PR-1577 — Allowlisted Host.PlatformConfig for core drivers

Status: done

## Summary

Scoped `Host.ConfigValue` stays limited to `plugins.<slug>.*`. Plugins that
must fail Init on an unsupported queue (or other driver) use
`Host.PlatformConfig` against a fixed non-secret allowlist
(`queue.driver`, `search.engine`, `cache.driver`, `media.storage`) and optional
`pluginsdk.RequireQueueDriver`. Secrets and other plugins' keys remain closed.

## Scope

- `config.PlatformConfigAllowlist` / `IsPlatformConfigKey`
- `Host.PlatformConfig` + `RequireQueueDriver`
- Scoping tests; DEVELOPER / EXTENSION_POINTS / AGENTS recipes

## Out of scope

- Widening `ConfigValue` itself
- New Cap* for queue driver
- Broker URLs / database fields on Host
- Metal Dogs product fork migration (product adopts after pin)

## Validation

```bash
go test ./pkg/pluginsdk/ -count=1 -run 'ConfigValue|PlatformConfig|RequireQueueDriver'
go test ./internal/platform/config/ -count=1 -run PlatformConfig
go test ./pkg/pluginsdk/ ./internal/platform/config/ -count=1
```
