# PR-1595 — WithJobID raced requeue retry

Status: done

## Summary

Concurrent `Enqueue(..., WithJobID(id))` on a terminal job: the loser got
`ErrRequeueWrongAttempt` / `ErrRequeueNotTerminal` and Enqueue failed, so Metal
Dogs kept its own retry around Enqueue.

- On `ErrRequeueNotTerminal` → success (peer already requeued; known drivers)
- On `ErrRequeueWrongAttempt` → Get once; re-check type; if still terminal
  Requeue with live attempt; if in-flight → success
- One-shot only: a second `WrongAttempt` is a hard error (`conflict requeue
  retry`) — best-effort, not an unbounded N-way guarantee
- Shared `classifySyncJobConflictStatus` for in-flight vs terminal

## Scope
