# PR-1588 — CR fixes for CapJobs / CapMedia / ParseMinorUnits (1582–1587)

Status: done

## Summary

Code review of PR-1582…1587: worker-like roots asserted CapJobs/CapMedia
before binding them, and `ParseMinorUnits` accepted non-ASCII digits that
folded incorrectly via `c-'0'`.

- Bind CapJobs/CapMedia **before** `assertWorkerNeedsMet` (scheduler, worker,
  search-reindex, jobs CLI, schedule CLI); jobs CLI also binds media.
- `assertWorkerLiteNeedsMet` skips CapJobs/CapMedia for cache / extension-field /
  discovery CLIs that never bind those ports.
- `ParseMinorUnits`: ASCII digits only; document single-separator decimal policy.
- Document `JobsPort.Get` `(nil, nil)` miss; harness binds CapJobs/CapMedia stubs
  (not mark-only).
