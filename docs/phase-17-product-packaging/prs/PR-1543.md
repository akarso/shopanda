# PR-1543 — Public pricing step contracts

Status: done

## Summary

- `extapi.PricingStep` + `PricingContext` (lines, AddAdjustment, meta).
- `pluginsdk.AdaptPricingStep` / Host coerces public steps to domain `pricing.PricingStep`.
- **Review follow-up**: `PricingLine` now carries per-line `Adjustments` (previously only visible internally via `pricing.PricingItem.Adjustments`, so a plugin step reading `Items()` after an earlier tax/discount step had no way to see what was already applied to a line). `PricingContext` gained `Adjustments()` (cart-level, mirrors `AddAdjustment`) and running totals `Subtotal()` / `Discounts()` / `Tax()` / `Fees()` / `GrandTotal()` as `Money` (populated by the core finalize step; zero before it runs). Implemented in `pricingContextView` (`pkg/pluginsdk/pricing_adapt.go`).
