# PR-1592 — `SyncJobs.Enqueue` `WithJobID` + `IsConflict`

Status: done

## Summary

Idempotent sync enqueue (Metal Dogs MIG3b) needs a stable queue job id.
`SyncJobs.Enqueue` always generated a new id, so plugins kept
`plugin.App.BoundQueue()`.

- `pluginsdk.EnqueueOption` / `WithJobID(id)` on `SyncJobs.Enqueue`
- Dual-mode `plugin.WithJobID` on `Integration.Enqueue`
- Duplicate id → `apperror.Conflict` returned **unwrapped** so
  `pluginsdk.IsConflict` is true; resume via `Host.Jobs().Get` / `Requeue`
- Empty `WithJobID` fails closed

## Scope

- `internal/platform/plugin/sync_job.go` + tests

## Out of scope
