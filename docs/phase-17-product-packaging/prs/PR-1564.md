# PR-1564 — CatalogSeedPort

Status: done

## Summary

`CatalogPort` stays read-only. Adds `CatalogSeedPort` (`CapCatalogSeed`) with
`Import(ctx, batch)` (one transaction when postgres WithTx repos are bound)
plus EnsureProduct / EnsureVariant / EnsurePrice / SetStock. Create-only /
idempotent by slug/SKU/price key. Amounts are minor units (plugins parse
display strings). Products can drop custom `metaldogs_catalog.go` wiring.

## Scope

- `pkg/pluginsdk.CatalogSeedPort` + adapter (`Import` + Ensure*)
- Bootstrap Prices / PriceHistory / Stock; BindCatalogSeedPort; Host.CatalogSeed
- Unit tests for EnsureProduct + Import slug resolution

## Out of scope

- Full Magento-style CSV importer
- Widening CapCatalog
- No C4 change — Host capability only (same container)
