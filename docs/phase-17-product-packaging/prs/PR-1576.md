# PR-1576 — Terminal job requeue (keep attempts + OnRequeued)

Status: done

## Summary

`Queue.Requeue` gains `WithRequeueTerminal()` for `failed` / `done` /
`cancelled` → `pending` while keeping `attempts`, setting `run_at=NOW()`,
leaving `last_error` unchanged, and running `OnRequeued` / `RequeueTx` in the
same Postgres transaction. `Admin.Retry` stays failed-only with `attempts=0`
and no hooks. CLI: `jobs:requeue --terminal`. Redis/brokers return
`ErrRequeueUnsupported` for terminal mode.

## Scope

- Domain: `WithRequeueTerminal`, `ErrRequeueNotTerminal`, `ResolveRequeueOptions`
- Postgres `RequeueWithBeforeCommit` terminal branch + acceptance tests
- Redis: unsupported for terminal
- CLI `--terminal` (+ help / RUNBOOK / EXTENSION_POINTS)

## Out of scope

- Changing `Admin.Retry` semantics
- Redis terminal parity
- HTTP admin requeue endpoint
- Metal Dogs product fork removal of raw `UPDATE jobs`
