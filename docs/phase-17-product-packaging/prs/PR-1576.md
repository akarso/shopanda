# PR-1576 — Terminal job requeue (keep attempts + OnRequeued)

Status: done

## Summary

`Queue.Requeue` gains `WithRequeueTerminal()` for terminal → `pending` while
keeping `attempts`, setting `run_at=NOW()`, leaving `last_error` unchanged,
and running `OnRequeued` / `RequeueTx` in the same Postgres transaction.
CLI: `jobs:requeue --terminal` (failed only); `--force` required for
`done`/`cancelled` (duplicate side-effect risk). Audit details include
`terminal` / `force` / `prior_status`. Missing id → `ErrRequeueNotFound`.
Redis/brokers → `ErrRequeueUnsupported`. Includes PR-1578 fixture cherry-pick
so DSN CI is not red if merge order slips.

## Scope

- Domain: `WithRequeueTerminal`, `ErrRequeueNotFound` / `NotTerminal`, options
- Postgres terminal branch + done/cancelled/missing tests
- Redis unsupported regression test; WrapRequeueNotify + terminal hooks
- CLI `--terminal [--force]`, README/RUNBOOK/help, audit details, conflict map
- Cherry-pick Warehousedemo media fixture (PR-1578)

## Out of scope

- Changing `Admin.Retry` semantics
- Redis terminal parity
- HTTP admin requeue endpoint
- Metal Dogs product fork removal of raw `UPDATE jobs`
