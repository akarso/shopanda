# PR-1553 — CartPort session cart + validate extension visibility

Status: done

## Summary

Closes the product-consumer follow-ups after Track E: expand `CartPort` beyond
`AddItem`, put stored line extension values on `extapi.CartLineView` for
`cart.validate` (owner-scoped), share the storefront guest cart cookie with
plugins, and add an `extref` design-on-line public route (idempotent / 409 /
fail-closed).

## Scope

- `CartPort`: `Get`, `EnsureActive`, `EnsureStorefrontCart`, `DeleteLineExtension`,
  `UpsertLineExtension`
- Guest session: replace non-active / not-found / Forbidden cookie carts;
  propagate other `GetCart` errors without rewriting the cookie; blank currency
  → store context then `EUR`; cookie `Secure` via `WithCookieSecure` (security
  middleware + trusted proxies)
- `CartView` via visibility-filtered `ListByCartItems` (batched); JSON payloads
  decode to structured values; private fields omitted; plugin-only omitted for
  non-owners (same rule for validate and `Get`)
- `Access.ExclusiveString` fields (design_id) rejected before `carts.Save`; plain
  + exclusive line fields write in one `UpsertBatchSelective` transaction
  (conditional `ON CONFLICT … WHERE` only on exclusive codes). A design conflict
  rolls back gift_note in the same batch before cart compensate
- Attributed `Host.Cart()` returns only owner-scoped `*cartPort` (fail closed);
  `WithPluginWrite` pinned to Host plugin name; AddItem/delete/upsert owner-checked
- `extref`: `extref.design_id` Required; `POST /extref/design-line` (CSRF `/extref/`);
  attach-without-qty-bump; errors mapped by `pluginsdk.Is*` code helpers
- Docs: ROADMAP Track E index includes PR-1553
