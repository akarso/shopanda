# PR-642 — Promotion Helper Admin UI (Track E, OSS stretch)

Status: done

## Summary

- Guided promotion templates for tiered, buy-X-get-Y, and common cart/catalog discounts
- Advanced JSON tab for raw conditions/actions editing

## Why

Promotions admin existed (PR-401/510) but tiered and BOGO rules were API-only; merchants had to guess JSON shapes.

## Scope

- `admin.js` — template selector, type-specific form sections, tier editor, advanced JSON panel
- `promotion_admin.go` — expose raw `conditions`/`actions` on read; `rules_mode: advanced` write path

## Out Of Scope

- New promotion engine rules
- Stackability policy changes
- Coupon bulk import UI
- Product/category-scoped conditions

## Validation

- Create tiered catalog promo via form; saves with `action_tiers`
- Create buy-X-get-Y via form; saves with `action_buy_qty` / `action_get_qty`
- Advanced JSON tab saves via `rules_mode: advanced`
- `go test ./internal/interfaces/http/... -count=1`

## What changed

- Promotion form templates: catalog/cart percentage, min quantity, tiered, BOGO, fixed cart
- Dynamic tier rows with add/remove; contextual show/hide for condition and action fields
- Grid discount column summarizes tiered/BOGO promos
- Admin API returns `conditions` and `actions` JSON; accepts advanced rules mode on write
- Tests: advanced rules create, admin JS wiring assertions
