# PR-630 — Bulk Price Admin Grid (Track D, OSS)

Status: done

## Summary

- Admin grid to view and edit variant prices by SKU with store/currency scope
- Reduce reliance on `app import:prices` for routine updates

## Why

Per-variant price on product edit works for single-SKU changes; catalog managers expect a spreadsheet-like price list in admin.

## Scope

- New admin route `/admin/catalog/prices` under Catalog
- Paginated grid using existing inventory list + per-variant price APIs
- Inline edit + save per row
- Respect store/currency context from admin header switcher

## Out Of Scope

- Replacing CSV import/export CLI
- Scheduled price rules, MAP pricing
- Multi-currency bulk edit in one view (single currency context per screen is OK)
- Dedicated bulk price list API (reuses inventory list for variant rows)

## Validation

- Load grid for active currency; edit one variant price; save persists
- Scope badge shows store override vs global vs global fallback
- User without `products.read` sees forbidden state; save requires `products.write`

## What changed

- Catalog → **Bulk Prices** nav link and `/admin/catalog/prices` route
- Searchable grid (SKU/product) backed by `GET /admin/inventory` for variant rows
- Per-row price load/save via existing `GET/PUT .../variants/{variantId}/price` endpoints
- Scope badges: store override, global, unset with global fallback hint
- Currency context required; scope banner explains active store/currency
- `products.read` / `products.write` client-side gating
- `admin_handler_test.go` — bulk prices wiring and nav assertions
