# PR-611 — Store Credit Admin UI (Track B, OSS)

Status: planned

## Summary

- Customer detail: show store credit balance and issue credit form
- Wire PR-505 admin store-credit API

## Why

Store credit issuance and checkout redemption exist, but merchants must use API to issue credit after returns or goodwill gestures.

## Scope

- `admin.js` — section on customer detail page
- `GET /api/v1/admin/customers/{id}/store-credit`
- `POST /api/v1/admin/customers/{id}/store-credit/issue`
- Currency selector aligned with store default

## Out Of Scope

- Gift cards
- Automatic credit from return approval
- Storefront account UI changes

## Validation

- Issue 25.00 EUR credit; balance updates on customer detail
- Permission denied shown for users without `customers.write`
- Ledger entries visible in summary list (read-only)
