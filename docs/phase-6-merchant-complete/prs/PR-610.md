# PR-610 — Customer Groups Admin UI (Track B, B2B)

Status: done

## Summary

- Replace Customers → Groups placeholder with group list, CRUD, and member assignment
- Wire PR-500/501 B2B admin APIs when `plugins.b2b` is licensed

## Why

Customer groups and group-aware pricing exist in `plugins/b2b/`, but OSS admin shows a placeholder. Licensed merchants cannot manage tiers from the UI.

## Scope

- `admin.js` — `/admin/customers/groups` when B2B plugin is enabled and licensed; upgrade/hidden state when disabled or unlicensed
- List/create/edit groups; assign/remove customers
- Link to group price management docs or future UI hook

## Out Of Scope

- OSS customer segmentation without B2B license
- Group-aware promotion UI (use existing promotion JSON/API)
- Net payment terms, quotes, PO flows

## Validation

- With B2B plugin enabled and licensed: create group, assign customer, list members
- Without license or when `plugins.b2b.enabled=false`: nav hidden or shows license hint (no placeholder crash)
- Group APIs unchanged; UI only

## What changed

- `/admin/customers/groups` — list groups with link to create/edit; license hint when B2B API unavailable
- `/admin/customers/groups/new` and `/admin/customers/groups/{id}` — create/edit group (code immutable after create), delete group
- Group edit page — assign/remove members (scans first 100 customers via existing per-customer membership API)
- Customer detail — **Customer Group** panel to view/assign/remove group when B2B is available
- Sidebar **Groups** link hidden when `GET /admin/customer-groups` returns 404 (plugin not loaded)
- `apiDelete` helper for 204 No Content responses from B2B DELETE endpoints
- `admin_handler_test.go` — customer groups wiring assertions
