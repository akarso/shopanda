# PR-640 — Product Reviews Admin UI (Track E, OSS stretch)

Status: planned

## Summary

- Admin list and moderate product reviews when reviews plugin/API is enabled
- Approve, reject, or hide reviews from storefront

## Why

Reviews may exist via API or plugin, but merchants need moderation without database access.

## Scope

- `admin.js` — `/admin/catalog/reviews` or product-detail reviews tab
- Wire existing review admin API if present; otherwise minimal read-only list from storefront API

## Out Of Scope

- Review submission on storefront (if not already shipped)
- Fake review import
- Syndication to Google

## Validation

- Pending review appears in admin; approve makes it visible on PDP
- Reject hides review from storefront
