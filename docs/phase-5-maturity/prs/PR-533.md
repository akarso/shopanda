# PR-533 — GPSR Product Safety (Track D)

Status: done

## Summary

- GPSR safety product attributes (manufacturer/importer contact, identifier, warnings, age restriction, conformity marking)
- `gpsr_safety_disclosure` composition block on PDP when store toggle `legal.gpsr_enabled` is on
- Store-level default manufacturer name and EU contact as product fallbacks
- Admin legal settings + attribute seeder for GPSR group

## Why

EU GPSR requires traceable manufacturer/importer contact and safety information on products sold in the EU. WEEE (PR-531) established the legal config + composition + attribute group pattern for compliance fields.

## Scope

- `internal/domain/legal/gpsr.go` — attribute keys, config keys, parse helpers
- `internal/application/composition/gpsr_step.go` — PDP `gpsr_safety_disclosure` block
- `internal/seed/gpsr_attributes.go` — GPSR attribute group (+ demo data on cotton-tshirt with `--demo-seed`)
- Admin: `legal.gpsr_enabled`, `legal.gpsr_manufacturer_name`, `legal.gpsr_manufacturer_contact`
- `themes/default/templates/product.html` — GPSR safety partial
- tests: domain, composition step, storefront PDP render

## Out Of Scope

- Category-driven required-field validation (future plugin)
- National safety registry filing
- Checkout-line GPSR disclosure

## Validation

- Seed registers GPSR attributes under Catalog → Attributes
- Enable `legal.gpsr_enabled` and set default manufacturer contact for a store
- Configure GPSR fields on a product → PDP shows manufacturer, warnings, markings
- REST API `/api/v1/products/{id}` returns `gpsr_safety_disclosure` block when enabled
