# PR-530 — Omnibus Storefront Verification (Track D)

Status: done

## Summary

- render EU Omnibus `price_indication` composition blocks on SSR product and listing pages
- per-store admin toggle `legal.omnibus_enabled` (default on)
- PLP cards show lowest 30-day price when discounted

## Why

Price history and `PriceIndicationStep` existed since Phase 1 (PR-099) but the default theme never displayed the block. EU merchants need visible lowest-prior-price on discounted products.

## Scope

- `internal/domain/legal/omnibus.go` — config key + scoped enabled lookup (default true)
- `PriceIndicationStep` — skip when disabled via store config
- `ListingPriceIndicationStep` — populate `Meta.price_indications` per product on PLP
- `themes/default/templates/product.html` + `product_list.html` — Omnibus disclosure
- admin Shipping settings — Legal / Omnibus checkbox (store-scoped)
- tests: legal config, composition disabled path, storefront PDP render

## Out Of Scope

- Promotional strikethrough styling beyond basic theme classes
- Recording price history changes (already in importer/seed)

## Validation

- product with lower 30d history shows Omnibus text on `/products/{slug}`
- listing card shows lowest price when applicable
- `legal.omnibus_enabled=false` for store suppresses blocks
- REST API `/api/v1/products/{id}` still returns `price_indication` block when enabled
