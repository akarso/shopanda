# PR-531 — WEEE Product Fields (Track D)

Status: done

## Summary

- WEEE compliance product attributes (category, producer registration, take-back info, symbol visibility)
- `weee_disclosure` composition block on PDP when store toggle `legal.weee_enabled` is on
- Store-level default producer registration in footer and as product fallback
- Admin legal settings + attribute seeder for WEEE group

## Why

EU electronics merchants must display WEEE recycling information on product pages. Phase 1–4 had no compliance fields; Omnibus (PR-530) established the legal config + composition pattern.

## Scope

- `internal/domain/legal/weee.go` — attribute keys, config keys, parse helpers
- `internal/application/composition/weee_step.go` — PDP `weee_disclosure` block
- `internal/seed/weee_attributes.go` — WEEE attribute group + demo data on wireless-mouse
- Admin: `legal.weee_enabled`, `legal.weee_producer_registration` in Shipping → Legal settings
- `themes/default/templates/product.html` — WEEE disclosure partial
- `themes/default/templates/layout.html` — footer producer registration line
- Storefront `WithLegalConfig` for footer helper
- tests: domain, composition step, storefront PDP render

## Out Of Scope

- National WEEE registry filing or automated reporting
- EPR packaging (PR-532) and GPSR safety (PR-533)
- Checkout-line WEEE disclosure

## Validation

- Seed registers WEEE attributes under Catalog → Attributes
- Enable `legal.weee_enabled` and set producer registration for a store
- Configure WEEE fields on an electronics SKU → PDP shows category, registration, take-back
- Footer shows store producer registration when WEEE enabled and registration set
- REST API `/api/v1/products/{id}` returns `weee_disclosure` block when enabled
