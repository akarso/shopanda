# PR-522 — Admin TOTP / MFA (Track C, OSS)

Status: done

## Summary

- Optional TOTP second factor for admin-panel login
- Self-service enrollment with recovery codes
- Two-step login flow when policy requires MFA

## Why

PR-520/521 improved admin identity management but login remained password-only. PR-522 adds optional MFA for admin roles with recovery codes and a deploy-time safety switch.

## Scope

- `migrations/059_admin_mfa.sql` — customer TOTP columns + recovery code table
- `internal/domain/mfa/` — repository port, recovery code generation
- `internal/domain/security/mfa_config.go` — `security.admin_mfa_required` config helper
- `internal/platform/mfasec/` — TOTP (RFC 6238), secret encryption, pending login tokens
- `internal/infrastructure/postgres/mfa_repo.go` — MFA persistence
- `internal/application/mfa/service.go` — enrollment, disable, login verification
- `internal/application/auth/service.go` — MFA-aware login + `VerifyLoginMFA`
- `internal/interfaces/http/auth.go` — login challenge + `POST /auth/login/mfa`
- `internal/interfaces/http/admin_mfa.go` — enrollment/management endpoints
- `internal/platform/config/config.go` — `auth.mfa_enabled` deploy flag
- `cmd/api/main.go` — wiring

## Out Of Scope

- Admin SPA login/enrollment UI (API only)
- Customer/storefront MFA
- WebAuthn / hardware keys
- Forced enrollment grace period workflow
- Email-based MFA

## Validation

- With `auth.mfa_enabled=true` and Postgres `security.admin_mfa_required=true`:
  - Enrolled admin login returns `mfa_required` + `pending_token` (no JWT)
  - `POST /api/v1/auth/login/mfa` with valid TOTP or recovery code returns JWT
- `GET /api/v1/admin/mfa` reports enrollment/policy state
- `POST /api/v1/admin/mfa/enroll` + `/enroll/confirm` enrolls TOTP and returns recovery codes once
- `DELETE /api/v1/admin/mfa` disables MFA after password confirmation and revokes sessions
- Storefront/customer login unchanged when MFA policy does not apply

## Configuration

- Deploy flag: `auth.mfa_enabled` / `SHOPANDA_AUTH_MFA_ENABLED` (default false)
- Merchant flag: Postgres config key `security.admin_mfa_required` (default false)
