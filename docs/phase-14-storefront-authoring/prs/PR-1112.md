# PR-1112 — Same-origin storefront cart JSON update/remove

Status: done

## Summary

PR-1111 added JSON add into the SSR cookie cart. Configurator scripts also need qty change and line remove without posting HTML forms.

## Scope

- `PUT /storefront/cart/items/{variantId}` — JSON `{quantity}` (must be > 0)
- `DELETE /storefront/cart/items/{variantId}` — no body
- Same cookie / signed-in active cart as add; leftover guest cookie ignored after login; 404 when there is no cart
- Same CSRF header (JSON 403 on missing/wrong token) and success envelope `{"data":{"item_count":n,"total_quantity":n,"cart_url":"/cart"},"error":null}` (no `cart_id`)
- HTML `/cart/update` and `/cart/remove` unchanged
- Routes exist only when HTML storefront is mounted (`StorefrontHTML()`)

## Out of scope

- Merging REST `cart_id` into the storefront cookie
- CORS on `/storefront/*`
- OpenAPI — SSR-only seam; see HEADLESS.md / PR-1111

```bash
go test ./internal/interfaces/http/shared ./internal/interfaces/http/storefront ./internal/application/cart ./internal/application/cache ./cmd/api
```
