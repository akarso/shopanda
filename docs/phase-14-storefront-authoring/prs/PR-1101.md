# PR-1101 — Static inheritance + cache-bust

Status: done

## Summary

Child themes inherit parent `static/` files. Theme CSS/JS URLs get a content-hash `?v=` so the 1-year Cache-Control does not stick after edits. Filesystem resolution lives in `themefs`, not domain.

## Scope

- `ResolvedTemplates.StaticRoots` (domain holds the list only)
- `themefs.ResolveStaticFile` / `ContentVersion` / `StaticURL` / `StaticHandler(rootsFn, noStore)`
- Layout URLs call `themefs.StaticURL` on each HTML render so a CSS/JS edit changes `?v=` without a restart
- Dev mode (`SHOPANDA_DEV_MODE`) sends `Cache-Control: no-store` on `/static/`
- Symlink targets outside the static root are not served

## Out of scope

- Full asset pipeline / hashed filenames on disk

## Validation

```bash
go test ./internal/domain/theme ./internal/infrastructure/themefs ./internal/interfaces/http/storefront
```

No C4 change — existing static route, inherited filesystem.
