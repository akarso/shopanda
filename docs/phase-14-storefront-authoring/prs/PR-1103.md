# PR-1103 — `theme:init` + `_starter`

Status: done

## Summary

Child-theme seed so authors do not copy the whole default theme.

## Scope

- `themes/_starter/` (`parent: ../default`, empty `custom.css`)
- `shopanda theme:init <name>` writes `<themes-root>/<name>`
- `themes-root` is the parent of `frontend.theme_path`, or `./themes`
- Name must match `[a-z0-9][a-z0-9_-]*`
- YAML written with `yaml.Marshal` (no string replace)

- Theme marketplace / zip install
