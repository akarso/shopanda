# PR-1108 — Addresses JSON + claim routes

Status: done

## Summary

Address book existed only as HTML. Guest claim JSON lived inside the SSR `if`.

## Scope

- `GET/POST /api/v1/account/addresses`
- `PUT/DELETE /api/v1/account/addresses/{addressId}`
- `POST /api/v1/account/addresses/{addressId}/default`
- Address PUT `is_default` is optional (`*bool`); omitted leaves the flag, `false` clears it
- HTML address form still uses checkbox-or (`existing || form`) and cannot clear default — use Set Default
- `POST /api/v1/orders/claim-search` and `claim-register` always mounted
- Claim search/register accept `application/json` or `application/x-www-form-urlencoded`
- SSR and headless share `attachStorefrontClaimAPI`
- Claim emails use `frontend.claim_url` (`SHOPANDA_FRONTEND_CLAIM_URL`); SSR falls back to `{public_base_url}/account/orders/claim`

## Out of scope

- Multi-step checkout JSON
- Login-and-link (claim-register is register-and-link only)
