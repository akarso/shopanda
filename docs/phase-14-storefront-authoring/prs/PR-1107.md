# PR-1107 — Slug lookup + opt-in snake_case JSON

Status: done

## Summary

Public product/category GET accepted UUID only. Nested `/variants` and `/reviews` used `FindByID` only. A first draft remapped catalog JSON to snake_case unconditionally — that is a silent break and is reverted.

## Scope

- `GET /api/v1/products/{id}` and `GET /api/v1/categories/{id}` accept id or slug
- Category products listing, variant parent lookup, and review parent lookup use the same resolver
- Default storefront product/category JSON keeps Go exported names
- Opt-in snake maps via `?fields=snake` or `X-Shopanda-Field-Names: snake` (no `pricing_mode` / `stock_mode` / `explode_order_lines`)
- Admin still encodes domain structs (Go names)

- Variant list snake_case (follow-up)
