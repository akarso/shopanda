# PR-1102 — Dev-mode theme watch

Status: done

## Summary

`SHOPANDA_DEV_MODE` polls theme.yaml / layout.yaml / templates and reloads the engine without a process restart. Static files already read from disk.

## Scope

- `themeapp.Stamp` / `WatchLoop(ctx)` — cancel on server shutdown
- Child `theme.yaml` is always in the stamp set (even when all pages come from the parent)
- On reload: `ReplaceEngine`, clear category nav cache, purge `fpc:` keys
- `StorefrontHandler.ReplaceEngine` (mutex-safe)

## Out of scope

- Production watch
- fsnotify dependency

## Validation

```bash
go test ./internal/application/theme ./internal/interfaces/http/storefront
```

No C4 change.
