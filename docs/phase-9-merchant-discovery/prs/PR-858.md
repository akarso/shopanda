# PR-858 — Reference Plugin: Export Remap

Status: done

## Summary

- Ship `plugins/exportdemo` reference plugin demonstrating ERP CSV column remap on `export:products`
- `export.product.row` maps core columns to SAP-style columns (`matnr`, `maktx`, …)
- Config + compile-time registration; unit tests

## Enable

```yaml
plugins:
  exportdemo:
    enabled: true
```

## Validation

- `go test ./plugins/exportdemo/...`
- `app export:products out.csv` with plugin enabled produces `matnr` column instead of `sku`
