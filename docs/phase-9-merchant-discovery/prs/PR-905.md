# PR-905 — Advanced Search Attribute Filters

Status: done

## Summary

- Storefront advanced search filter panel on `/search` for attributes flagged `use_in_advanced_search`
- Public search API attribute query params on `GET /api/v1/search`
- Builds on PR-901 autosuggest and PR-902 attribute metadata

## Why

PR-901 shipped header autosuggest but deferred attribute filtering. PR-902 added `use_in_advanced_search` flags; merchants could mark attributes but shoppers could not filter by them yet.

## Scope

- `GET /api/v1/search` — accept `attr_<code>=<value>` for flagged attributes
- `internal/application/admin/attributes.go` — `ListAdvancedSearchAttributes`
- `internal/interfaces/http/search_attribute_filters.go` — shared attr filter helpers
- `internal/interfaces/http/search.go` — `WithAdvancedSearchAttributes`, API filter wiring
- `internal/interfaces/http/storefront_advanced_search_filters.go` — `/search` filter panel (advanced-only attrs)
- `cmd/api/main.go` — wire attribute store to search handler + storefront
- Tests: search API + storefront search filter round-trip

## Out Of Scope

- Meilisearch attribute filters (Postgres default first; same deferral as PR-904)
- Replacing or extending PR-901 autosuggest
- Promotion rules consuming `use_in_promo_rules`
- Admin changes beyond existing PR-902 property flags
- Advanced search filters on `/products` or category pages (search page only)

## Storefront behavior

| Param | Example | Effect |
| --- | --- | --- |
| `attr_<code>` | `/search?q=shirt&attr_brand=acme` | Filters search results where `attributes.brand = acme` |

On `/search`, attributes flagged **Use in advanced search** appear as facet chips when PostgreSQL search returns counts. Attributes already shown via layered navigation (`use_in_layered_nav`) are not duplicated.

## API behavior

`GET /api/v1/search?q=shoes&attr_brand=nike` applies the filter when `brand` is flagged for advanced search. Unlisted `attr_*` params are ignored.

## Dependencies

- **PR-902** — `use_in_advanced_search` attribute metadata (done)
- **PR-901** — storefront search entry + autosuggest (done)
- **PR-904** — postgres `attr_*` filter/facet patterns (done; reused)
