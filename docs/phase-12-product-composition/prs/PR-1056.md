# PR-1056 — Admin vs. Public/Storefront API Split

Status: done

## Summary

- Formalize the boundary: admin/operator paths see every product regardless of computed/overridden visibility; public/storefront surfaces use a shared axis gate keyed by `VisibilitySurface` **in addition to** Status scope (PR-1054).
- Audited REST + HTML/SSR + fragment routes → axis mapping (executable contract); leave per-handler enforcement to PR-1057/1058.

## Why

In a headless deployment the public API *is* the storefront. Visibility must be enforced at a single API boundary, not as a per-handler convention. Admin stays unrestricted at the wiring layer (`AdminContextMiddleware`), matching the PR-1054 status-scope pattern. HTML/SSR routes are the same boundary — omitting them from the audit would leave holes for 1057.

## Scope

- `catalog.VisibilitySurface`, `Visibility.AllowedOn`, `AllowProduct`, `FilterProducts` (always copies; post-fetch only).
- `catalog.WithBypassProductVisibility` / `WithOperatorProductReadScope`; admin path match is `/api/v1/admin` or `/api/v1/admin/…`.
- Operator import/export/seed set the same operator scope as admin HTTP.
- Audited route → surface table: `storefront.PublicProductVisibilityRoutes()` (REST, HTML PLP/PDP/search/category, fragments, cart/checkout deferred to 1058) + DEVELOPER.md.
- Explicit decisions: `POST …/reviews` → `individually`; checkout / cart qty-up → `purchasable` (EnforceIn PR-1058); cart GET / mini-cart → `out-of-scope` (already-in-cart display; 1058 may re-check).

## Out Of Scope

- Wiring the gate into storefront handlers — PR-1057.
- Cart/checkout purchasability enforcement — PR-1058 (routes listed now with EnforceIn).
- Loading stock/price/store facts for AutoBasis in handlers — PR-1057/1058.
- Query-level visibility predicates / recount after LIMIT — PR-1057.
- GraphQL — PR-1082.

## What changed

- One domain axis gate for all four surfaces; Status remains a separate gate.
- Admin + operator bypass at middleware/job entry, not per handler.
- Route audit is fail-closed in tests (every method+path+surface+EnforceIn asserted).
