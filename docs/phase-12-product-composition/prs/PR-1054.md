# PR-1054 — Enforce `Status = active` in Core Read Paths

Status: done

## Summary

- Product repository reads (`List`, `FindByID`, `FindBySlug`, `FindByCategoryID`) return only `StatusActive` rows by default; admin API and export opt in via context or `ListFilter.IncludeNonActive`.
- `cart.Service.AddItem`, quantity updates (qty &gt; 0), guest-cart claim (assign + merge) reject non-active products; checkout `ValidateCartStep` rejects stale lines at checkout time.
- Product CSV import and seed runs opt into non-active reads so existing draft/archived slugs update correctly.

## Why

Draft and archived products were publicly listable and addable to cart because core read paths and cart never checked lifecycle status. This closes that gap before the four-axis visibility model (PR-1055).

## Scope

- `catalog.WithIncludeNonActiveProducts` read scope; `ListFilter.IncludeNonActive`.
- `internal/infrastructure/postgres/product_repo.go` status filtering.
- Admin middleware sets include-non-active on `/api/v1/admin` paths; product/EPR exporters set scope on ctx.
- Cart service wired with variant + product repos; purchasability on add/update/claim(assign+merge); checkout validation on complete.
- Importer/seed set `WithIncludeNonActiveProducts` at entry (same pattern as export).
- Sitemap drops redundant in-handler active filter (repo list is active-only).

## Out Of Scope

- Four-axis visibility (`VisibleInCatalog`, `Purchasable`, …) — PR-1055.
- Formal storefront vs admin repository split / dedicated admin catalog reader — PR-1056 (context opt-in is the interim seam).
- Search index ingestion still scans all statuses (query paths already filter active); unchanged here.
- Mapping checkout `ValidateCartStep` plain errors to typed `apperror` HTTP codes — pre-existing checkout error surface; follow-up if storefront shows generic 500.

## What changed

- Default product reads are active-only; admin/export/import/seed preserve full catalog visibility via explicit scope.
- Cart add/update/claim and checkout fail closed when the backing product is not active.
