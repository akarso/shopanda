# PR-1066 — Bundle/Grouped Admin API + CSV + GUI

Status: planned

## Summary

- Component/member picker: admin API + CSV import/export for `bundle_component`/`grouped_member` rows.
- Corresponding admin GUI section, wired via PR-1053's type-specific section mechanism.

## Why

Track C's domain/pricing/stock work (PR-1060–1065) is unusable by a merchant without a way to actually define components/members and see the result — this PR closes that loop, matching the "admin reachability means API, CLI/CSV, and GUI, not just a domain model" principle carried over from Phase 11.

## Scope

- Admin API: add/remove/list `bundle_component`/`grouped_member` rows for a given parent product, including `quantity`/`required` for bundle components.
- CSV import/export: new columns/file for composition rows, following the existing importer/exporter error-reporting conventions.
- Admin GUI: a component/member picker (search + add existing products, set quantity/required for bundle components) in the product edit form's bundle/grouped section.
- `openapi.yaml`: document the new endpoints.

## Out Of Scope

- Nothing further within Track C — this is the closeout PR.
