# PR-1078 — Admin API + CSV + GUI for Downloadable Management

Status: planned

## Summary

- File attach/replace, grant list/revoke per customer.
- Admin GUI section, wired via PR-1053's type-specific section mechanism.

## Why

Closes Track E's admin-reachability loop, same principle as PR-1066 (Track C) and PR-1073 (Track D) — support needs to re-issue a grant (lost access, wrong file version) or investigate a customer's complaint about a download that failed, without direct SQL.

## Scope

- Admin API: attach/replace file on a `downloadable` product; list a customer's grants for a given order/product; revoke a grant; re-issue a fresh grant (new expiry/count) for a customer who legitimately needs one (support escalation path).
- CSV: file-attachment metadata (not the files themselves) round-trips through the existing product import/export pipeline alongside `type` (PR-1052).
- Admin GUI: file management section on the product edit form; grant list/revoke on the order/customer detail view.
- Audit log entries for revoke/re-issue, matching the pattern established across every other admin-write action in this codebase.

## Out Of Scope

- Nothing further within Track E — this is the closeout PR.
