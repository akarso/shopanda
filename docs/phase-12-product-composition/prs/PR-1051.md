# PR-1051 — Admin API Type Field Support

Status: done

> **Numbering note:** Phase 12 Track A — unrelated to any Phase 11 PR id.

## Summary

- Admin product create/update accept optional `type` (validated via `Product.Validate` → `422`).
- Admin product list accepts `?type=` filter; invalid values return `422`.
- Migration `085` adds composite `idx_products_type_created_at` on `(type, created_at DESC)`.
- `catalog.ProductRepository.List` takes `catalog.ListFilter` (empty `Type` = all; non-empty invalid → validation error).
- `openapi.yaml` documents request/filter `type`; responses already expose Go field `Type`.

## Why

PR-1049 shipped the column and domain validation; operators still could not set or filter by type over the admin API. This PR is HTTP + list plumbing only — type-specific behavior remains later tracks.

## Scope

- `createProductRequest` / `updateProductRequest` + handlers set `Type` before `Validate()`.
- Blank/`whitespace` create `type` is omit (keeps `simple`); update with present but blank `type` → `422` `"type must not be empty"`; omit on update preserves existing type.
- `GET /api/v1/admin/products?type=` → `ListFilter.Type` (HTTP + repo both reject invalid types via `catalog.InvalidTypeMessage`).
- Composite index matching `WHERE type = $n ORDER BY created_at DESC`.
- OpenAPI: `ProductType` query param, create/update request properties, update `422`, response examples include `Type`.

## Type mutability (policy)

Type remains **mutable** after create (operators may correct a mistaken default `simple`). Changing `simple` ↔ `virtual`/`downloadable` changes `RequiresPhysicalShipping` for **new** carts (PR-1050 resolves the requirement in `ValidateCartStep`). In-flight carts that already cached shipping meta are unchanged until the next checkout validation. Types such as `bundle`/`grouped`/`configurable`/`downloadable` can be stored before their tracks ship — they have incomplete behavior until those PRs land. See RUNBOOK.

## Out Of Scope

- Type-specific request fields (bundle components, downloadable files, etc.).
- Freezing type after create / transition matrix — deferred unless product policy requires it.
- CSV / admin GUI — PR-1052 / PR-1053.
- Renaming JSON keys on `catalog.Product` responses (`Type` vs `type`) — pre-existing envelope shape.
