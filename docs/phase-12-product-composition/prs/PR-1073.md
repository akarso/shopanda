# PR-1073 — CSV Import/Export + Admin GUI

Status: planned

## Summary

- Bulk eligibility-rule import/export.
- Card detail page showing assigned tickets, ticket detail showing its current card, assign/revoke actions.

## Why

Closes Track D's admin-reachability loop, matching the same principle Track C's PR-1066 closes for bundle/grouped — a domain model and an API alone aren't reachable enough for day-to-day merchant/support use.

## Scope

- CSV import/export for `LinkedProduct` eligibility rules (PR-1067) — bulk-defining which tickets are eligible for which cards/categories.
- CSV/bulk-operation support for assignment isn't in scope for direct CSV (assignment is inherently transactional/order-tied, not a bulk catalog edit) — confirm during implementation whether an admin bulk-assign tool (distinct from CSV) is worth adding here or is better left to PR-1071's API being scriptable directly.
- Admin GUI: card detail page section listing assigned tickets (via PR-1071's list endpoint), ticket detail page showing its current card (if any) and assignment history, assign/revoke action buttons — wired via PR-1053's type-specific section mechanism.
