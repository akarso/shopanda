# PR-1016 — RBAC Registry Injection

Status: planned

## Summary

- Eliminate package-level mutable plugin permission registry in `domain/rbac`
- Register permissions through composition root / `plugin.App`

## Why

`rbac.RegisterPluginPermission` mutates global state (forbidden by AGENTS.md) and already breaks `TestPermissionsForRole_Admin` via registration pollution.

## Scope

- Introduce injectable registry or collect permissions during plugin `Init` into app-owned structure
- Update plugins that register permissions
- Make tests hermetic (no cross-test pollution)
- Preserve permission strings and admin enforcement behavior

## Out Of Scope

- Redesigning RBAC model / roles UX

## Validation

- `go test ./internal/domain/rbac/... ./internal/interfaces/http/... ./plugins/...`
- Parallel `go test` stable
