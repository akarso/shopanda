# PR-1021 — HTTP Package Split (Shared)

Status: planned

## Summary

- Extract shared HTTP primitives (router, middleware, JSON helpers, auth middleware) into a subpackage
- Leave handlers in place for this PR to keep review small

## Why

Flat `package http` ~170 files hurts compile times and reviewability. Split must be incremental.

## Scope

- Create `internal/interfaces/http/shared` (or `internal/interfaces/httpserver`) with movable pieces
- Update imports in handlers
- No URL changes

## Out Of Scope

- Moving admin/storefront handlers (PR-1022/1023)

## Validation

- `go test ./internal/interfaces/...`
- `go build ./cmd/api/`
