# PR-1020 — Prometheus Metrics

Status: planned

## Summary

- Expose `/metrics` (Prometheus text format)
- Instrument RED metrics for HTTP, plus checkout/queue/webhook counters

## Why

Zero metrics today. For commerce (orders, payments, queues) logs alone are insufficient for A+.

## Scope

- Choose lightweight client (`prometheus/client_golang`)
- Metrics: request count/latency/status; checkout success/fail; job failures; webhook delivery success/fail
- Config flag to enable; document scrape config
- Basic tests (handler registers metrics; counter increments)

## Out Of Scope

- Full Grafana dashboards (provide example queries in docs only)
- OpenTelemetry (PR-1024)

## Validation

- `go test` for metrics package/middleware
- Scrape `/metrics` locally after a few requests
