# PR-1015 — Typed Plugin Providers

Status: planned

## Summary

- Replace `RegisterX(provider any)` with concrete interface parameters
- Fail at compile time when a plugin registers the wrong type

## Why

~71 `any` usages in `platform/plugin`; wrong types fail only at startup via type assert. Undermines Go’s type system at the extension boundary.

## Scope

- Typed methods for search/cache/queue/media/tax/mail/shipping/etc. providers already known
- Update core + demo plugins to compile
- Remove redundant runtime asserts where possible (keep defensive checks at edges)
- Tests: compile-time via assignments; registry unit tests

## Out Of Scope

- Full SDK extraction from `internal` (PR-1017 honesty + later)
- Changing provider behavior

## Validation

- `go build ./...`
- `go test ./internal/platform/plugin/... ./plugins/...`
