# PR-1001 — Repo Hygiene

Status: planned

## Summary

- Stop tracking the compiled `api` binary; ignore it going forward
- Format the tree with `gofmt`; remove dead migration copy
- Tighten `.dockerignore`

## Why

The 50MB `api` binary was recommitted across many PRs and inflated `.git` (~2GB loose objects). 86 files fail `gofmt -l`. Stale `internal/infrastructure/postgres/migrations/022_create_promotions.sql` is unused.

## Scope

- Add `api`, `.DS_Store` to `.gitignore`
- `git rm --cached api` (do **not** rewrite history in this PR)
- Add `api`, `install.sh` to `.dockerignore`
- `gofmt -w` on all Go sources (or at least files currently failing `gofmt -l`)
- Delete unused `internal/infrastructure/postgres/migrations/022_create_promotions.sql` if still unreferenced
- Optional: delete local junk under `src/tmp_logo*.png` if present

## Out Of Scope

- `git filter-repo` history rewrite (coordinate separately after merge; document in PR notes)
- CI workflow (PR-1002)

## Validation

- `git ls-files api` → empty
- `gofmt -l .` → empty
- `go test ./...` still green (depends on PR-1000)
