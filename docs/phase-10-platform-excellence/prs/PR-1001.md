# PR-1001 — Repo Hygiene

Status: done

## Summary

- Stop tracking the compiled root `api` binary; ignore it going forward
- Format the tree with `gofmt`; remove dead migration copy under `internal/infrastructure/postgres/migrations/`
- Tighten `.dockerignore`
- Note in `DEPLOYMENT.md`: ship via build/image, not committed binaries

## Why

The 50MB `api` binary was recommitted across many PRs and inflated `.git` (~2GB loose objects). 86 files failed `gofmt -l`. `internal/infrastructure/postgres/migrations/022_create_promotions.sql` was unused: runtime and tests load root `migrations/` via `migrate.Run(..., "migrations")` / `../../../migrations`.

## Scope

- Add `/api` (repo-root only) and `.DS_Store` to `.gitignore`
- `git rm --cached api` (do **not** rewrite history in this PR)
- Add `api`, `install.sh` to `.dockerignore`
- `gofmt -w` on all Go sources
- Delete unused `internal/infrastructure/postgres/migrations/022_create_promotions.sql`
- Update `DEPLOYMENT.md` + Phase 10 index/ROADMAP status for this PR

## Out Of Scope

- `git filter-repo` history rewrite (coordinate separately after merge; document in PR notes)
- CI workflow (PR-1002)
- Renaming or deleting anything under root `migrations/`
- Local untracked junk under `src/` (already covered by `.gitignore` `src`; never git-tracked — **N/A**)
- Phase 10 **planned-spec tightenings** for PR-1002–1026 (plan CR) — separate docs change; see [`PLAN_CR.md`](../PLAN_CR.md)
