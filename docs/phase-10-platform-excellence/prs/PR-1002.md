# PR-1002 — GitHub Actions CI (Unit)

Status: planned

## Summary

- Add `.github/workflows/ci.yml` that blocks PRs on format/vet/unit tests
- No Postgres required in this job (DB tests skip without DSN)

## Why

AGENTS.md requires runnable/testable PRs but nothing enforces it. Interface changes already shipped with broken tests.

## Scope

- Workflow on `pull_request` + `push` to `main`/`dev`
- Steps: checkout, setup-go (match `go.mod` version), `gofmt -l` (fail if dirty), `go vet ./...`, `go test ./...`
- Cache Go modules
- Badge optional in root README

## Out Of Scope

- Postgres integration job (PR-1003)
- Docker image build (can be a non-blocking job later or in PR-1010)
- golangci-lint (optional later)

## Validation

*(planned — run when implementing)*

- `go test ./...`
- `go build ./cmd/api/`
- Open a draft PR: workflow runs green on current tree after PR-1000/1001
- Intentionally break a test in a throwaway branch: workflow fails
