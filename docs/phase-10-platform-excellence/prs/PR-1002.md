# PR-1002 — GitHub Actions CI (Unit)

Status: done

## Summary

- Add `.github/workflows/ci.yml` that **runs** format/vet/unit tests on PRs and pushes to `main`/`dev`
- No Postgres required in this job (DB tests skip without DSN)
- Document the separate admin step to **require** check `CI / unit` for merge blocking

## Why

AGENTS.md requires runnable/testable PRs but nothing enforces it. Interface changes already shipped with broken tests.

## Scope

- Workflow on `pull_request` (bases `main`/`dev`) + `push` to `main`/`dev`
- Steps: checkout, setup-go (match `go.mod`, cache via `go.sum`), `go mod verify`, `gofmt -l`, `go vet ./...`, `go test ./...`
- `GOFLAGS=-mod=readonly` for reproducible module graph
- Concurrency group with `cancel-in-progress`
- CI badge in root README
- Contributor expectations + branch-protection admin step in `DEVELOPER.md`

## Out Of Scope

- Postgres integration job (PR-1003)
- Docker image build (can be a non-blocking job later or in PR-1010)
- golangci-lint (optional later)
- Automating GitHub rulesets via API/Terraform (manual admin step)

## Merge gate (admin — not in git)

Require status check **`CI / unit`** on branches `main` and `dev` (GitHub Ruleset or classic branch protection). Without this, CI only reports; merges are not blocked.
