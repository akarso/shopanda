# PR-1014 — Collapse Import/Export CLI

Status: planned

## Summary

- Replace ~14 near-identical `runImport*` / `runExport*` functions with one shared runner
- Single place to open DB, build repos, init plugin registry, log errors

## Why

~700 LOC of copy-paste; each command reconstructs plugin registry independently (7+ `NewRegistry` call sites today).

## Scope

- Shared helper: `runIOCommand(cfg, kind, path, hook)`
- Preserve CLI flag/UX and exit codes
- Deduplicate plugin registry bootstrap used by CLI
- Tests for at least one import and one export path (table-driven)

## Out Of Scope

- Changing CSV schemas
- New import/export entities

## Validation

- `go test ./cmd/api/...`
- Manual smoke: `app import:products` / `export:products` against dev DB
