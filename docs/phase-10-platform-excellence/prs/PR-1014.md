# PR-1014 — Collapse Import/Export CLI

Status: done

## Summary

- Replace ~14 near-identical `runImport*` / `runExport*` functions with one shared runner
- Single place to open DB, build file handles, bootstrap plugin row-hook registries, log errors

## Why

~700 LOC of copy-paste; each command reconstructed plugin registry independently.

## Scope

- Shared helper: `runIOCommand(cfg, log, opts, hook)` in `cmd/api/io_command.go`
- Thin per-entity wrappers in `cmd/api/io_commands.go`
- Preserve CLI flag/UX and exit codes
- Deduplicate plugin registry bootstrap call site into the shared runner (`WithHooks`)
- Table-driven tests for import + export paths (`io_command_test.go`)

## Out Of Scope

- Changing CSV schemas
- New import/export entities
- `config:import` / `config:export` YAML commands

## What changed

| Area | Change |
| --- | --- |
| `cmd/api/io_command.go` | Shared DB/file/logging/atomic-export orchestration |
| `cmd/api/io_commands.go` | Thin `runImport*` / `runExport*` + epr/oss arg parsers |
| `cmd/api/main.go` | Removed ~14 inlined clone bodies; dispatch unchanged |
| `cmd/api/import_plugins.go` / `export_plugins.go` | Unchanged helpers; called once from `runIOCommand` when `WithHooks` |
| Tests | `requireIOPath`, epr/oss parsers, import/export `runIOCommand` paths (no live DB) |

Behavior notes preserved: products export still uses direct `os.Create` (non-atomic); attributes import still uses tx + discovery facet sync; epr/oss still skip row hooks. Import opens the CSV **before** the DB connect/ping (historical UX).
