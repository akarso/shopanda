# PR-1005 — JWT Secret Strength

Status: planned

## Summary

- Reject JWT secrets shorter than 32 bytes at startup
- Align installer / examples with the rule

## Why

`jwt.NewIssuer` only checks non-empty. Weak secrets allow offline forging of admin tokens.

## Scope

- Validate in `internal/platform/jwt` and/or `platform/config/validate.go`
- Clear error message naming the env var
- Update `install.sh` / `.env.example` comments (installer already generates 32-byte hex — keep that)
- Tests for reject/accept lengths

## Out Of Scope

- Rotating secrets / multi-key JWT
- Moving off HS256

## Validation

- `go test ./internal/platform/jwt/... ./internal/platform/config/...`
- Empty/short secret → process refuses to start
