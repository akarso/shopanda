# PR-1314 — Admin dashboard + feedback

Status: planned

## Summary

- Dashboard: `stat-card` grid restyle, section headings, recent-activity lists using PR-1312 table/list styles.
- Feedback components: inline alert (info/success/warning/danger), toast for save results, loading state (skeleton or spinner), confirm dialog via native `<dialog>`.

## Why

Merchants currently get inconsistent or missing feedback after actions; the dashboard is the landing page.

## Scope

- `admin.css` feedback section; `admin.js` helpers for alert/toast/confirm replacing ad-hoc messages and `window.confirm` where present.
- Toasts announce via `aria-live="polite"`.
- Before/after screenshots: dashboard, a save success, a save error, a delete confirm.

## Out Of Scope

- New dashboard metrics or APIs.
- Charts.

## Decisions

- Toast position and auto-dismiss timing — propose with recommendation.
