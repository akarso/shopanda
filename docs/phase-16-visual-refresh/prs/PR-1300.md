# PR-1300 — Design audit + baseline

Status: planned

## Summary

- Playwright baseline screenshots of admin and default storefront at 1440px and 390px.
- Systematic audit (hierarchy, spacing, type, color, contrast, consistency, responsive, states).
- Findings ranked by severity, each mapped to the Phase 16 PR that fixes it.

## Why

Restyling without a baseline produces opinions, not improvements. Later PRs need a fixed "before" and a checklist to close.

## Scope

- `specs/DESIGN_AUDIT.md`: findings table (surface, route, issue, severity, owning PR).
- Baseline screenshots under `docs/phase-16-visual-refresh/baseline/` (admin: dashboard, orders list, order detail, product edit, settings general, media; storefront: home, category, PDP, cart, each checkout step, account pages).
- Inventory of ad-hoc admin component classes (`settings-scope-note`, `stat-card`, `chip`, `badge`, `admin-form-hint`, …) and inline styles in `admin.js`.
- Inventory of literal colors / font stacks / spacing values in `themes/default/static/css/style.css`.
- Contrast spot-check of current palettes.
- Skills: `design-audit`, `webapp-testing`.

## Out Of Scope

- Any CSS, template, or JS change.
- Direction decisions (PR-1301).

## Decisions

None — audit reports, it does not choose.

## Follow-up

- PR-1301 — direction, informed by findings.
