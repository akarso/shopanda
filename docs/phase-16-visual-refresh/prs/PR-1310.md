# PR-1310 — Admin foundation

Status: planned

## Summary

- Vendor Pico v2 into `internal/interfaces/http/admin/dist/vendor/` (with license); drop the jsDelivr `<link>` from `index.html`.
- Add the admin token layer (primitives + semantic) from `DESIGN_DIRECTION.md` at the top of `admin.css`, mapped onto `--pico-*` variables.
- Type scale and base element styles.
- Icon sprite (`dist/icons.svg`) if D8 = yes; nothing uses it yet beyond a smoke usage.

## Why

Every later admin PR consumes these tokens. Removing the CDN makes the admin work offline / behind strict egress and removes a supply-chain dependency.

## Scope

- `index.html`: local stylesheet links only.
- `admin.css`: tokens block; replace existing literal colors with semantic tokens; no layout rules changed.
- `admin_handler_test.go`: assert vendored CSS is served; no `https://` stylesheet in `index.html`.
- Visible effect limited to palette and type.
- Skills: `design-system`, `typography`, `webapp-testing` (before/after).

## Out Of Scope

- Layout, nav, tables, forms (PR-1311–1313).
- Dark mode (PR-1315).
