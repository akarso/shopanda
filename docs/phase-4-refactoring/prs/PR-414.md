# PR-414 — Redis Cache Driver + Core Plugin (Track B)

Status: done

## Summary

- implement `cache.Cache` Redis backend in `internal/infrastructure/redis`
- package as `plugins/core/rediscache`; activate when `cache.driver=redis`
- Postgres cache remains default

## Why

Only a Postgres cache implementation exists today (`cache.driver=postgres`). Redis is documented as optional but not implemented. Merchants scaling beyond single-node Postgres cache need a config-only switch.

## Scope

- Redis `cache.Cache` implementation: get/set/delete with TTL support matching existing cache port contract
- config: `cache.driver=redis`, connection URL/host (`REDIS_URL` or structured config), key prefix optional
- `plugins/core/rediscache`: init client, register cache provider; fail init if Redis unreachable when driver is redis
- `main.go` uses registered cache from plugin wiring; remove inline Postgres-only switch growth
- tests: unit tests with miniredis or integration tag; config validation

## Out Of Scope

- Redis queue (PR-415)
- Cache stampede protection beyond existing behavior
- Distributed locking

## Validation

- `cache.driver=postgres`: no Redis connection; behavior unchanged
- `cache.driver=redis` with Redis up: cache read/write works for a representative path (e.g. catalog composition cache if applicable)
- `go test ./internal/infrastructure/redis ./plugins/core/rediscache -count=1`

## What changed

- **`internal/infrastructure/redis/`**: `CacheStore` implementing `cache.Cache` with JSON serialization, TTL via Redis `SET`, prefix-aware `DeleteByPrefix` (SCAN), and no-op `DeleteExpired` (Redis evicts TTL keys)
- **`plugins/core/rediscache/`**: registers Redis cache when `cache.driver=redis`; validates URL (`cache.redis.url`, `SHOPANDA_CACHE_REDIS_URL`, or `REDIS_URL`); PING on init
- **`plugins/core/register.go`**: if/else-if registers one cache plugin (postgres or redis)
- **`core_plugins.go`**: `CoreRedisCacheEnabled()`
- **`config.go`**: `cache.redis.url`, `cache.redis.key_prefix`; env overlays for `REDIS_URL`, `SHOPANDA_CACHE_REDIS_*`
- **Tests**: miniredis contract tests; plugin init guards; register selection
