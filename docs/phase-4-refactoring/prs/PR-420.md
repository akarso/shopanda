# PR-420 — Example External Plugin (Track C)

Status: done

## Summary

- add `plugins/example/` demonstrating an external plugin: pricing step, event listener, and permission registration
- register in `main.go` behind `plugins.example.enabled` (default off)

## Why

The plugin interface and registry exist, but there is no in-repo example of a third-party-style package. Authors need a copy-paste starting point that does not live under `plugins/core/` and does not modify domain code.

## Scope

- `plugins/example` package implementing `plugin.Plugin`
- `Init` registers:
  - a trivial pricing step (e.g. fixed minor-unit adjustment or logging step) behind a config flag
  - an event listener on an existing domain event (e.g. order placed) that logs or no-ops
  - an admin permission string used in a test or documented RBAC check
- config: `plugins.example.enabled` default `false`
- `main.go`: `registry.Register(example.New())` when enabled via config or compile-time import with guard
- README in `plugins/example/README.md` with enable steps
- tests: plugin init registers steps; disabled by default in default config test

## Out Of Scope

- Plugin marketplace
- Dynamic `.so` loading
- CLI commands from plugins

## Validation

- with `plugins.example.enabled=true`, pricing pipeline includes the example step (unit test)
- with default config, example plugin not registered or inactive
- `go test ./plugins/example -count=1`

## What changed

- **`plugins/example/`**: reference external plugin (`example/demo`) with fee pricing step, `order.created` async listener, and `example.reports.read` permission
- **`cmd/api/register_plugins.go`**: registers core plugins plus example plugin when enabled
- **`config.go`**: `plugins.example.enabled`, `plugins.example.fee_minor_units`; env overlays
- **Tests**: plugin init, pricing pipeline fee, RBAC registration, default config disabled
- **`plugins/example/README.md`**: enablement instructions for authors
