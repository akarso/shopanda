# PR-403 — Admin Inventory Visibility (Track A)

Status: done

## Summary

- deliver a stock list with search/filter and per-SKU quantity adjust in the admin operations area
- wire `/admin/operations/inventory` off the placeholder over the existing `stock` repository

## Why

Inventory reservations and stock decrements work in checkout, and the dashboard shows a low-stock count, but there is no page to inspect or adjust quantities. Merchants rely on `app import:stock` / `export:stock` for routine stock management.

## What changed

- `InventoryListItem` + `StockRepository.ListInventory` — enriched list with SKU, product/variant labels, reserved qty
- `InventoryAdminHandler` at `/api/v1/admin/inventory` (list) and `PUT .../{variantId}` (absolute quantity set)
- RBAC: `ProductsRead` / `ProductsWrite`; audit: `stock.read`, `stock.update` with before/after quantity
- shared `admin.LowStockThreshold` (10) used by inventory UI and dashboard stats
- admin UI: searchable grid, inline adjust, low-stock badge

## Scope

- admin API: `GET /api/v1/admin/inventory` (paginated list: SKU, product/variant label, qty on hand, reserved qty if available from repo); `PUT /api/v1/admin/inventory/{variantId}` for absolute quantity set or delta adjust (pick one, document in PR)
- admin UI: searchable grid; inline or modal adjust; low-stock badge consistent with dashboard threshold
- audit: stock adjustments logged with before/after quantity
- tests: handler tests for list, adjust, validation (non-negative stock)

## Out Of Scope

- Multi-warehouse inventory
- Stock movement history UI
- Reservation management / manual release
- Reorder points configuration UI

## Validation

- merchant can find a variant by SKU and set stock quantity; storefront availability reflects the change
- negative stock rejected
- `go test ./internal/interfaces/http -count=1`

## Adjust semantics

`PUT` sets **absolute** on-hand quantity (same as CSV import / `SetStock`).
