# PR-431 — Production Compose & Deploy Layout (Track D)

Status: done

## Summary

- add `worker` and `scheduler` services to `docker-compose.yml` (production-oriented profile or default alongside `app`)
- update `DEPLOYMENT.md` and `MERCHANT.md` with three-process layout and prominent "emails require worker" guidance

## Why

Compose today runs `app` + `postgres` only. Operators following Compose as reference deploy miss background email and scheduled jobs. Production documentation should match the runtime contract in `RUNTIME_MODES.md`.

## Scope

- `docker-compose.yml`: `worker` and `scheduler` services using same image as `app`, commands `worker` and `scheduler`; shared env and depends_on postgres
- optional profiles: `prod` vs `dev` (Mailpit) — align with existing profile patterns
- `DEPLOYMENT.md`: minimum production checklist (serve, worker, scheduler, SMTP, migrate)
- `MERCHANT.md`: note that order emails need worker running
- `RUNTIME_MODES.md`: production section reflects compose services
- no application code changes unless required for health/readiness

## Out Of Scope

- Kubernetes manifests
- Horizontal autoscaling guides
- RabbitMQ/Redis compose services (covered by PR-416/414 profiles when those PRs land)

## Validation

- `docker compose up` (with documented profile) brings up app + worker + scheduler + postgres
- order triggers email job consumed by worker container (Mailpit in dev profile)
- docs accurately describe service count and commands

## What changed

- **`docker-compose.yml`**: added `worker` and `scheduler` services with shared `x-shopanda-common` anchor; explicit `command: serve` on `app`; disabled image healthcheck on worker/scheduler (no HTTP port); mail env uses `${SHOPANDA_MAIL_SMTP_*}` substitution from `.env`
- **`DEPLOYMENT.md`**: default compose layout documents four services; production checklist; replaced manual override example with built-in background process table
- **`MERCHANT.md`**: email section notes worker requirement and troubleshooting step
- **`RUNTIME_MODES.md`**: production mode marked implemented; compose quick-start commands added
