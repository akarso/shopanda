# PR-430 — Dev Single-Process Mode (Track D)

Status: done

## Summary

- add `app dev` (or `serve --with-worker`) that runs HTTP server and embedded worker in one OS process
- optional embedded scheduler for local parity; document in `RUNTIME_MODES.md`

## Why

Transactional email and async jobs require a worker. `serve` already embedded a worker since PR-080, but local dev still lacked an embedded scheduler and a discoverable dev command.

## What changed

- `app dev` command: HTTP + embedded worker + embedded scheduler (when `dev.embed_scheduler` is true, default)
- `serve` unchanged for production-style use: HTTP + worker only (no scheduler)
- `internal/platform/runtime`: shared `RegisterCacheCleanup` and `ShutdownBackground`; reused by `runScheduler`
- config: `dev.embed_scheduler` + `SHOPANDA_DEV_EMBED_SCHEDULER`
- docs: `RUNTIME_MODES.md`, `README.md`, `install.sh`, `configs/config.example.yaml`

## Scope

- new `dev` command that starts:
  - HTTP server (same as `serve`)
  - background worker loop in a goroutine (same handler registry as `worker` command)
  - embedded scheduler when `dev.embed_scheduler` is true (**default: `true`** — provides local parity with production cache-cleanup scheduling; disable via config or `SHOPANDA_DEV_EMBED_SCHEDULER=false`)
- graceful shutdown: cancel context, drain worker, stop scheduler, stop HTTP
- `install.sh` / README quickstart: recommend `app dev` for local work
- update `specs/RUNTIME_MODES.md` development section from "target" to "implemented"
- automated tests: `RegisterCacheCleanup` unit test verifies task name, cron cadence, and enqueue wiring (`go test ./internal/platform/runtime/...`)

## Out Of Scope

- Hot reload
- Combining production `serve`+`worker` into one process in prod
- Docker Compose dev service change (optional doc note only)

## Validation

### Automated

- `go test ./internal/platform/runtime/... -count=1` — scheduler registration and enqueue wiring

### Manual (not covered by unit tests)

- `./app dev` → place order with Mailpit → confirmation email appears without a separate worker/scheduler terminal
- Ctrl+C shuts down cleanly without hung goroutines
