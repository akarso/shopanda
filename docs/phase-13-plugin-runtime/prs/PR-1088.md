# PR-1088 — SDK + docs + example

Status: planned

## Summary

- `pluginsdk` helpers for manual sync jobs (`RegisterManual`, `Enqueue`).
- Document the site-ready contract; show `plugins report` trigger kind `manual`.
- Stop presenting inline `OnAsync` work as the way to do slow plugin I/O.

## Why

PR-1087 is unused if authors cannot find it. Phase 8 already taught `RegisterCron` / `RegisterOnEvent`; this PR is the same surface for “run later.”

## Scope

- `pkg/pluginsdk` — register + enqueue wrappers (same pattern as PR-850).
- PLUGINS.md extension table, DEVELOPER.md, EXTENSION_POINTS.md registries table, PLUGIN_COMPOSITION.md task table.
- `./app plugins report` (and startup summary if it already lists sync jobs) includes `manual`.
- `plugins/example`: enqueue a no-op/demo job or document why the current `OnAsync` listener must stay tiny.

## Out Of Scope

- New reference plugin (warehouse demo stays cron).
- Generic job types.
- Admin GUI for plugin jobs (Phase 11 jobs UI is enough).

## Follow-up

- None in this phase. A later generic `RegisterJobHandler` only if a plugin cannot honestly use `integration.sync.*`.
