# PR-1088 — SDK + docs + example

Status: done

## Summary

- `pluginsdk` helpers: `RegisterManual` + `Enqueue` (run-now); document `RegisterOnEvent` as the primary event→queue path.
- `plugins report` shows `trigger=manual` / `trigger=cron(…)` / `trigger=event(…)`.
- Example plugin uses `RegisterOnEvent("demo.order_created", order.created, …)` so envelope `trigger=event`.

## Why

PR-1087 is unused if authors cannot find it. Phase 8 already taught `RegisterCron` / `RegisterOnEvent`; this PR surfaces Manual for “run later” without teaching Manual as the default event path.
