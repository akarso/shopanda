# PR-1085 — Move B2B onto `RunPluginFS`

Status: planned

## Summary

- B2B `Init` calls `RunPluginFS` with plugin name `shopanda/b2b` (or `Name()`) instead of `RunFS`.
- Treat already-applied B2B basenames as applied under the new keys so existing deployments do not re-run DDL.

## Why

PR-1084 is unused until the one in-tree plugin with tables uses it. Changing the version key without a backfill would re-exec `CREATE TABLE` on every shop that already ran B2B `Init`.

## Scope

- `plugins/b2b/migrations.go` — `RunPluginFS`.
- One-time mapping: if `001_create_customer_groups.sql` / `002_create_customer_group_prices.sql` exist in `schema_migrations` and the namespaced key does not, insert the namespaced key (do not re-exec SQL).
- B2B plugin/init tests updated; integration test when `SHOPANDA_TEST_DSN` is set.
- `plugins/b2b/README.md` notes namespaced versions.

## Out Of Scope

- Registering migrations on `plugin.App` (PR-1086).
- Renaming the SQL files (unnecessary once the tracking key is namespaced; renaming would desync old basename rows).

## Follow-up

- PR-1086 — `app migrate` applies registered plugin FS.
