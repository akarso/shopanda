Status: planned

## Summary

- Close the remaining holes around the plugin-write marker and add the missing tests deferred in PR-1091.

## Why

PR-1091 strips the marker in the event bus and `cart.AddItem` only, and lists these tests as not covered.

## Scope

- Strip the marker (`extensionapp.StripPluginWrite`) wherever core forwards `ctx` to foreign code outside the event bus: pricing pipelines, workflows, job queues, webhooks; add a test or lint that fails on new `ctx`-forwarding sites.
- Optionally an import-boundary rule so only the bus and the extension service import `platform/pluginwrite`.
- Tests: checkout and order endpoints return `forbidden_plugin_only_field`; strip for other events and async/worker paths; `WithPluginWrite` panic in a goroutine; handler-level 500 for a repo error in the definition guard.

## Out of scope

- Anything not listed above (one PR = one responsibility).
