# PR-1087 — `manual` trigger + `Enqueue` + queue bind

Status: done

## Summary

- Third sync-job trigger: `extapi.Manual()` (no cron, no event).
- `app.Integration(slug).Enqueue(ctx, name, payload)` enqueues `integration.sync.{slug}.{name}` on the **bound** queue (any registered job — on-demand / "run now"; envelope `trigger` is always `manual`).
- Composition root calls `BindQueue` after `resolveJobQueue` (serve/`setupWorker`, worker, scheduler, schedule CLI, search reindex). `boundQueue` is distinct from plugin `RegisterQueue`.

## Why

Plugins cannot enqueue today: `Bootstrap` has no queue, and `app.Queue()` is the backend slot filled by core plugins / `resolveJobQueue` **after** `InitAll`. Inbound webhooks and admin “run now” need 202 + retry, not a long `OnAsync` body.

Keep the existing type namespace and `RegisterSyncJobHandlers` path so Phase 11 jobs admin works with no new UI.

## Scope

- `pkg/extapi` — `SyncTriggerManual`, `Manual()`, `ErrSyncJobNotFound`, `ErrSyncJobQueueUnbound`.
- `registerSyncJob` accepts `manual` (no cron spec / event name); stores trimmed name + normalized slug.
- `Integration.Enqueue`; errors: unknown name, queue not bound (boundQueue only).
- `plugin.App.BindQueue` → `boundQueue`; `NewSyncJobEnvelope` shared with cron/event enqueue.
- Worker registration unchanged (already iterates `SyncJobs()`).
- Tests: register + enqueue payload shape; bind required; RegisterQueue alone does not unlock Enqueue; scheduler resolve+bind; duplicate type still rejected; cron/event skip manual; Handle round-trip; `-race` on touched packages.

## Out Of Scope

- Generic `jobs.Handler` / free-form types (`email.send` remains core-only).
- SDK wrappers and plugins-report `trigger=manual` listing (PR-1088).
- HTTP admin “trigger plugin job” route (use `Enqueue` from the plugin’s own route, or existing `jobs` retry).
- Cross-plugin slug ownership on `Enqueue` / `RegisterSyncJob` — same gap as registration; deferred until a plugin-init ownership handle exists.

## What changed

- `pkg/extapi` — `Manual()` + typed enqueue errors.
- `internal/platform/plugin` — accept manual trigger; `boundQueue` + `BindQueue`; `Integration.Enqueue`; `NewSyncJobEnvelope`.
- `internal/application/integration` — cron/event enqueue uses shared envelope.
- `cmd/api` — `runScheduler` uses `resolveJobQueue` + `BindQueue` (fixes default-config boot); other resolve sites bind.
- Docs: PLUGINS, PLUGIN_COMPOSITION, DEVELOPER, phase index/roadmap.
