# PR-1084 — `RunPluginFS` + lock + namespaced versions

Status: done

## Summary

- Add `migrate.RunPluginFS(ctx, db, pluginName, fsys, dir)` that applies pending SQL like `RunFS`, records versions as `plugin:{pluginName}:{basename}`, and takes `pg_advisory_xact_lock` **per file** (PgBouncer-safe; lock scope does not accumulate across files).

## Why

`schema_migrations` tracks by basename. Core tests already hit this (PR-1003). B2B’s `001_create_customer_groups.sql` is unique only by luck. `RunFS` has no lock; `serve` and `worker` both `Init` and can both attempt the same `CREATE TABLE`. Session `pg_advisory_lock` breaks under PgBouncer transaction pooling. A single batch transaction would keep B2B 003’s ACCESS EXCLUSIVE held through 004’s `VALIDATE CONSTRAINT` full-table scan — undoing the deliberate 003/004 split.

## Scope

- `internal/platform/migrate` — `RunPluginFS` / `RunPluginFSOptions`, per-file xact lock, claim-then-exec version insert, ctx + configurable lock wait (`DefaultPluginLockWait` = 5m, `ErrMigrationLockHeld`).
- Strict plugin-name charset; plugin filename hygiene; reject `CREATE INDEX CONCURRENTLY`; empty `.sql` set errors.
- `ensureTable` in autocommit before file txs; retry only on SQLSTATE `23505`.
- Leave `Run` / `RunFS` basename behaviour unchanged (PR-1085 backfill depends on it).
- RUNBOOK + DEPLOYMENT: per-file lock scope, PgBouncer, no CONCURRENTLY / top-level txn control.
- Tests: deterministic lock hold, timeout → `ErrMigrationLockHeld`, conflict skip without re-exec, partial failure keeps prior file, lock released between files, ctx cancel during SQL, `RunFS` basename regression.

## Out Of Scope

- Switching B2B over (PR-1085).
- `RegisterMigrations` / `app migrate` (PR-1086).
- Opt-in whole-batch atomic mode.

## What changed

- `internal/platform/migrate/migrate.go` — per-file `BeginTx(ReadCommitted)` → try-lock → `INSERT … ON CONFLICT DO NOTHING RETURNING` → SQL only on claim → commit; options + sentinel error.

- `internal/platform/migrate/plugin_fs_test.go` — coverage above.
