# PR-351 - Admin Products Screen Error Handling (Track 3)

Implemented the next visible Track 3 production slice by tightening the admin products screen's failure handling so permission, session, and backend load failures render the right user-facing message instead of collapsing into a generic error or an incorrect empty state.

## Summary

The admin products page fetched both:

- `GET /api/v1/admin/grids/product.grid`
- `GET /api/v1/admin/products?page=1&per_page=20&sort=created_at&order=desc`

But its client-side handling only treated one specific failure path specially:

- product data `forbidden` -> show products access message

Other failure modes were not surfaced correctly:

- grid schema `forbidden` fell back to `Failed to load grid or data.`
- unauthorized responses were not translated into a reauthentication prompt
- non-forbidden product data failures could degrade into the wrong UI state because invalid product payloads were normalized before validating the response shape

This PR fixes that products-screen behavior directly.

## Why This Slice

This is a small, visible production improvement:

- no backend contract changes
- no route changes
- no permission model changes
- directly improves one of the most obvious admin surfaces when product access is broken or the session is stale

## Changes

### Admin UI

Updated ../../../internal/interfaces/http/admin/dist/admin.js:

- Treat `forbidden` from either the grid schema request or the products data request as a products-access error
- Treat `unauthorized` from either request as a session-expired prompt
- Validate the grid payload before rendering and show `Failed to load product grid.` when the schema request fails
- Validate the products payload before normalizing it and show `Failed to load products.` when the products request fails
- Preserve backend error messages through `extractErrorMessage(...)` where available
- Avoid incorrectly converting invalid products responses into an empty products state

### Tests

Updated ../../../internal/interfaces/http/admin_handler_test.go:

- Added static asset coverage for:
  - `Your session expired. Sign in again to load products.`
  - `Failed to load product grid.`
  - `Failed to load products.`
