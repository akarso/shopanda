# PR-388: Assigned Product Page Totals in Category Assignment Panel

## Summary

Category product assignment now reports assigned products page totals in the admin UI.

## Motivation

The category assignment panel already tracked assigned product paging, but it only displayed the current page number. Adding total page counts improves pagination clarity for admins.

## Changes

### internal/interfaces/http/admin/dist/admin.js

- Added computation for `totalAssignedPages` in the category product assignment renderer.
- Updated the assigned products page note to display:
  - `Assigned products page X of Y.`

### internal/interfaces/http/admin_handler_test.go

- Added a static JS bundle guard for the new assigned products page total message.

## Validation

```bash
go test ./internal/interfaces/http -run TestAdminHandler_StaticJS -count=1
go test ./internal/interfaces/http -count=1
```

Both commands pass.
