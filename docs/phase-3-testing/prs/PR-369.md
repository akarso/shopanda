# PR-369 Product Assignment Category Filter

## Summary


Adds a small usability and scalability follow-up to the admin assignment panels.

- adds a client-side `Filter categories` search input to the product edit category assignment panel
- adds a client-side `Filter products` search input to the category edit product assignment panel
- filters both available category options and the assigned category list without adding a new backend endpoint
- filters both available product options and the assigned product list without adding a new backend endpoint
- keeps assign/remove flows on the existing admin category assignment routes

- **adds paging controls to the assigned-products list on the category edit page** (mirrors product picker paging, scalable for large assignments)
