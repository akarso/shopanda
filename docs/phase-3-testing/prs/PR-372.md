# PR-372 Product Assigned Categories Paging

## Summary

Adds the next scalability slice to the admin product edit assignment surface.

- adds client-side paging controls for the product edit assigned-categories list
- keeps assign/remove actions on existing category assignment endpoints
- preserves assigned-categories page position after assign/remove reloads
- auto-adjusts the page offset when removals make the current assigned page invalid
- resets assigned-categories paging to page 1 when the category filter changes
