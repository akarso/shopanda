# PR-386: Accessible Status Feedback for Admin Category Assignment Messages

## Summary

Assignment messages in the admin category/product assignment panels now use `role="status"`
and `aria-live="polite"` for non-error notifications, making transient UX feedback
announced to assistive technologies.

## Motivation

The admin assignment flows already rendered success and progress messages, but non-error
feedback was not exposed as an accessible live region. This slice improves accessibility
without changing existing UI behavior.

## Changes

### internal/interfaces/http/admin/dist/admin.js

- Updated non-error `setMessage` behavior in multiple admin message helpers to use:
  - `role="status"`
  - `aria-live="polite"`
- This applies to:
  - category admin lists
  - category product assignment
  - product category assignment

### internal/interfaces/http/admin_handler_test.go

- Extended static JS wiring coverage to assert `aria-live="polite"` is present.
