# PR-387: Accessible Remove Button Labels for Assignment Tables

## Summary

Remove actions in admin product/category assignment tables now include explicit `aria-label` text for assistive technologies.

## Motivation

The assignment tables displayed remove buttons with only the visible label "Remove", which is ambiguous when read out of context by screen readers. Adding descriptive labels improves accessibility and clarifies the action target.

## Changes

### internal/interfaces/http/admin/dist/admin.js

- Added accessible `aria-label` values for remove buttons in:
  - product-to-category assignment rows
  - category-to-product assignment rows
- Labels now include the assigned item name, slug, or id.

### internal/interfaces/http/admin_handler_test.go

- Extended static bundle guards to assert `aria-label="Remove product` and `aria-label="Remove category` are present.

## Validation

```bash
go test ./internal/interfaces/http -run TestAdminHandler_StaticJS -count=1
go test ./internal/interfaces/http -count=1
```

Both commands pass.
