# PR-375 Category Product Filter Resets Paging

## Summary

Adds a small UX consistency follow-up to the category edit product assignment panel.

- resets both the available-product picker page and assigned-products page to page 1 when the shared product filter changes
- reloads assignment data after filter changes so server-paged lists align with the new filter context
- keeps existing assign/remove endpoints and paging controls unchanged
