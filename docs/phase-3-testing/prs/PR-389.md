# PR-389: Explicit Action Headers in Assignment Tables

## Summary

Assignment tables in admin category/product assignment panels now use explicit action column headers.

## Motivation

The assignment tables currently render controls under an empty header cell, which hurts table semantics and makes keyboard/screen reader navigation less clear. Adding action headers improves the table structure without changing layout or behavior.

## Changes

### internal/interfaces/http/admin/dist/admin.js

- Replaced empty action column headers with `Action` in:
  - category-to-product assignment table
  - product-to-category assignment table

### internal/interfaces/http/admin_handler_test.go

- Added static JS bundle guard coverage for the new table header text.

## Validation

```bash
go test ./internal/interfaces/http -run TestAdminHandler_StaticJS -count=1
go test ./internal/interfaces/http -count=1
```

Both commands pass.
