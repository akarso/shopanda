# PR-374 Product Assigned Categories Filtered Paging Clamp

## Summary

Adds a small UX correctness follow-up to product edit category assignment paging.

- clamps assigned-categories page offset against the filtered assigned list before rendering
- prevents empty assigned-categories pages when assign/remove or filtering shrinks result counts
- preserves the existing assign/remove flows and paging controls
