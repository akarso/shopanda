# PR-376 Robust Assigned Categories Offset Clamp

## Summary

Adds a small robustness follow-up to product edit category assignment pagination.

- replaces one-step fallback with a last-valid-page offset clamp for assigned categories
- applies the clamp during both assignment reloads and filtered render paths
- prevents multi-page offset drift from landing on empty assigned-category pages
- keeps existing assignment endpoints and controls unchanged
