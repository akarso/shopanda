# PR-391: Accessible Labels for Category Reordering and Delete Controls

## Summary

Category tree move and delete buttons now include descriptive `aria-label` attributes for screen readers.

## Motivation

The category management tree displays move up/down and delete buttons without accessible labels, making it unclear to keyboard and assistive technology users which category each control targets. Adding descriptive aria-labels improves accessibility.

## Changes

### internal/interfaces/http/admin/dist/admin.js

- Added `aria-label` attributes to category tree controls:
  - Move up button: `aria-label="Move category {name} up"`
  - Move down button: `aria-label="Move category {name} down"`
  - Delete button: `aria-label="Delete category {name}"`

### internal/interfaces/http/admin_handler_test.go

- Extended category CRUD routing guard to assert `aria-label="Move category` and `aria-label="Delete category` are present.

## Validation

```bash
go test ./internal/interfaces/http -run TestAdminHandler_StaticJS -count=1
go test ./internal/interfaces/http -count=1
```

Both commands pass.
