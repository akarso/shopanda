# PR-379: Page X of Y totals for product-edit category assignment panels

## Summary

Both the assigned-categories and available-categories paging labels in the product-edit
category assignment panel now display the total page count alongside the current page
number (e.g. "Page 2 of 4.").

## Motivation

The product-edit panel loads the full category tree in memory and splits it into
assigned/available lists. Because the totals are known client-side, showing only
"Page N." withheld easily available orientation information from the user.

## Changes

### `internal/interfaces/http/admin/dist/admin.js`

- In `renderProductCategoryAssignmentBody`: compute `totalAssignedPages` and
  `totalAvailablePages` from `filteredAssignedCategories.length` and
  `filteredAvailableCategories.length` respectively (clamped to 1 minimum).
- Update "Available categories page N." label to "Available categories page N of Y."
- Update "Assigned categories page N." label to "Assigned categories page N of Y."

### `internal/interfaces/http/admin_handler_test.go`

- Extended the product detail assignment guard to assert `totalAssignedPages` and
  `totalAvailablePages` are present in the static bundle.
