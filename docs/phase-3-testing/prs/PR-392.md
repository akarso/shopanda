# PR-392: Add scope="col" to Admin Table Headers

## Summary

All major admin tables now use `<th scope="col">` for header cells, improving accessibility for screen readers and aligning with best practices for table semantics.

## Motivation

Previously, admin tables used plain `<th>` elements for headers. Adding `scope="col"` ensures assistive technologies can correctly interpret table structure, making navigation and comprehension easier for users with disabilities.

## Changes

### internal/interfaces/http/admin/dist/admin.js

- Updated all major admin tables to use `<th scope="col">` for header cells, including:
  - Product grid
  - Variant table
  - Orders table
  - Assigned products table
  - Assigned categories table

### internal/interfaces/http/admin_handler_test.go

- Updated static JS guard test to expect new header markup with `scope="col"`.
