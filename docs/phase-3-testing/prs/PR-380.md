# PR-380: Product Assigned Categories Name/Slug Column Split

## Summary

The product-edit category assignment table now renders assigned categories with separate
Name and Slug columns instead of combining both values into a single cell.

## Motivation

Recent slices made category assignment search slug-aware and improved pagination context.
Separating Name and Slug in the assigned table improves scanability and aligns this panel
with the existing product-assignment table pattern that already exposes slug as a first-class column.

## Changes

### internal/interfaces/http/admin/dist/admin.js

- In `renderProductCategoryAssignmentBody`, changed assigned categories table header from:
  - `Name | (actions)`
  to:
  - `Name | Slug | (actions)`
- Updated assigned category rows to render:
  - name in the first cell
  - slug (or id fallback) in the second cell
- Updated empty/no-match row `colspan` values from `2` to `3`.

### internal/interfaces/http/admin_handler_test.go

- Extended static JS wiring checks to assert the assigned-table slug rendering token:
  - `assigned.slug || assigned.id`

## Validation

```bash
go test ./internal/interfaces/http -run TestAdminHandler_StaticJS -count=1
go test ./internal/interfaces/http -count=1
```

Both commands pass.
