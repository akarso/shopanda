# PR-332 — PR-I Full Context Triad Visibility In Scoped Settings UI (Track 3)

## Summary

Implemented the next Track 3 slice by extending scoped settings UX to show the full active context triad across settings surfaces:

- settings scope banners now display language and currency alongside store scope
- scope resolution now consumes API scope payloads for store/language/currency with safe header-context fallback
- added static asset assertions to lock in triad visibility behavior

This keeps PR-I small while improving explicit context visibility and reducing hidden scope assumptions in feature-local configuration pages.

## Scope

- internal/interfaces/http/admin/dist/admin.js
  - replaced store-only scope resolution with `resolveSettingsScope(...)` that resolves:
    - `storeID`
    - `language`
    - `currency`
  - extended `settingsPayloadFromResult(...)` to consume:
    - `scope.store_id`
    - `scope.language`
    - `scope.currency`
  - updated settings pages to pass full resolved scope into banner rendering:
    - `renderSettingsPage`
    - `renderShippingSettingsPage`
    - `renderPaymentSettingsPage`
  - updated `renderSettingsScopeBanner(...)` to include language/currency metadata in banner copy

- internal/interfaces/http/admin_handler_test.go
  - added JS asset assertions verifying scope banner language/currency context markers:
    - `Language: <strong>`
    - `Currency: <strong>`

## Behavior

### Full context-aware banner messaging

Settings, Shipping, and Payments pages now communicate effective context as:

- store override/global scope status
- active language (when present)
- active currency (when present)

### Safer context derivation

UI scope metadata is now sourced first from API payload scope values and falls back to current header switcher context only when payload fields are missing.

## Why this slice

Track 3’s target state requires visible scope and no hidden inference for store/language/currency. Earlier slices made scope available in contracts and headers; this slice completes the operator-facing visibility by surfacing the full triad directly in scoped settings banners.
