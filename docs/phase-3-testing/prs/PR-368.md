# PR-368 Category Product Assignment

## Summary

Adds the smallest viable admin-side category-to-product assignment slice.

- exposes admin category product reads at `GET /api/v1/admin/categories/{id}/products`
- adds explicit assignment writes with:
  - `POST /api/v1/admin/categories/{id}/products/{productId}`
  - `DELETE /api/v1/admin/categories/{id}/products/{productId}`
- implements explicit join-table writes through `ProductCategoryAssignmentRepository`
- adds a category edit page panel for assigning and removing products
