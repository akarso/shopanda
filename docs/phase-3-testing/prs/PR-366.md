# PR-366 - Admin Categories CRUD Slice (Track 3)

Followed up the admin categories read slice by implementing category create, update, and delete in the backend and rewiring the admin Categories surface from a read-only tree into a minimal CRUD flow.

## Summary

The previous slice introduced `GET /api/v1/admin/categories` so the admin UI no longer depended on the public category tree endpoint.

This PR completes the next bounded step for that surface:

- `GET /api/v1/admin/categories`
- `GET /api/v1/admin/categories/{id}`
- `POST /api/v1/admin/categories`
- `PUT /api/v1/admin/categories/{id}`
- `DELETE /api/v1/admin/categories/{id}`

## Why This Slice

This keeps the Track 3 categories work small but real:

- adds the first full admin write path for categories
- reuses the existing category repository instead of introducing a new application abstraction
- keeps permission enforcement explicit with `categories.read` and `categories.write`
- fixes rewrite cleanup concerns that category slug updates and deletes would otherwise introduce

## Changes

### Backend

Updated ../../../cmd/api/main.go:

- Added `CategoryAdminHandler` wiring
- Added `RequirePermission(rbac.CategoriesWrite)` for create, update, and delete routes
- Added `GET /api/v1/admin/categories/{id}` behind `categories.read`

Added ../../../internal/interfaces/http/category_admin.go:

- Implemented `Create`, `Update`, and `Delete` handlers for admin categories
- Validates parent category existence
- Rejects self-parenting and parent cycles during updates
- Publishes category created, updated, and deleted events

Updated ../../../internal/domain/catalog/category_repository.go:

- Added `Delete(ctx, id)` to the repository contract

Updated ../../../internal/infrastructure/postgres/category_repo.go:

- Implemented category delete persistence
- Returns conflict when deleting a category that still has child categories
- Returns not found when deleting a missing category

Updated ../../../internal/domain/catalog/events.go:

- Added `catalog.category.deleted`
- Added `old_slug` support to category updated events so rewrite cleanup can remove stale paths

Updated ../../../internal/application/rewrite/subscriber.go:

- Removes old category rewrites when a category slug changes
- Removes category rewrites when a category is deleted

### Admin UI

Updated ../../../internal/interfaces/http/admin/dist/admin.js:

- Replaced the read-only Categories page with a minimal CRUD flow
- Added `New Category` and `Edit Category` routes
- Added create and edit forms backed by `/api/v1/admin/categories`
- Added inline delete actions from the category tree and edit form
- Added JSON validation for category meta input

### Tests

Updated ../../../internal/interfaces/http/admin_handler_test.go:
