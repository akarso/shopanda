# PR-706 — Checkout Order-Item Snapshot (Track C, OSS)

Status: planned

## Summary

- On checkout completion, copy `storage_mode=snapshot` cart_item extensions to matching order_item rows
- Order admin/API exposes extension values on line items

## Why

Custom line data must survive checkout for fulfillment and support; snapshot policy makes propagation explicit and deterministic.

## Scope

- Checkout workflow step (or order creation hook) implementing snapshot rules from registry
- `order_item` value storage reuses PR-703 repo with new target_type
- Order detail admin shows line extensions (read-only list)
- Tests: cart with extension → placed order retains values on items

## Out Of Scope

- Post-order edits to extension values
- Refund/cancel extension side effects

## Validation

- Field marked snapshot on cart_item appears on order_item after checkout
- Non-snapshot fields do not copy unless policy says so
- Order GET/admin includes extension payload on lines
