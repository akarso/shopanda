# PR-719 — Theme Author Guide (Track F, OSS)

Status: done

## Summary

- `docs/guides/THEME_SLOTS.md` — theme author guide for slots, inheritance, partials, and plugin coordination
- Cross-links from `PLUGINS.md`, phase-7 README, and PR index

## Why

Tracks F PR-711–715 and PR-718 documented anchors and plugin registration from the **plugin author** side. Theme authors still lacked a single guide for preserving injection points when overriding templates, using `parent:` inheritance, and splitting layout partials.

## Scope

- Guide sections:
  - theme directory layout and `theme.yaml`
  - child theme inheritance (`parent:`, child-wins overlay)
  - layout partials (`_header`, `_nav`, `_footer`)
  - `slot_container` vs explicit `slot` markers and placements
  - standard anchor catalog (aligned with `slots.StandardAnchors()`)
  - plugin coordination (preserve anchors, assets vs slots, dev warnings, admin slots API)
  - nested `slot_container` limitation and checklist
- Links to `PLUGINS.md`, `EXTENSION_API.md`, `plugins/slotsdemo`, default theme templates

## Out Of Scope

- Code changes to theme engine or slot registry
- `layout.yaml` block ordering (PR-716)
- Nested `slot_container` preprocessor fix (PR-717)
- Strict anchor validation CI mode (PR-720)

## Validation

- Guide anchor table matches `slots.StandardAnchors()` in `internal/application/slots/catalog.go`
- Inheritance and partial behavior matches `internal/domain/theme/inherit.go` and PR-712/713 specs
- Default theme file references exist under `themes/default/templates/`
