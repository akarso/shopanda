# PR-710 — GraphQL Extension Parity (Track E, OSS)

Status: done

## Summary

- GraphQL queries/mutations for extension field definitions and values
- Same ACL and private-field semantics as REST (PR-702, PR-703)

## Why

Headless and plugin clients using GraphQL need parity with admin REST without a second authorization model.

## Scope

- Extend GraphQL plugin schema: `extensionFields`, `extensionValues`, upsert/delete mutations
- Resolvers delegate to application extension services (not direct DB)
- Tests: public field round-trip; private field hidden; mutation forbidden without capability

## Out Of Scope

- Storefront GraphQL exposure of cart extensions (REST/cart API sufficient for Phase 7)
- Subscriptions

## Validation

- GraphQL query returns same product extension values as REST GET
- Private field omitted without privileged flag
- Invalid value returns same validation error shape as REST

## What changed

- **`plugins/core/graphql/schema.go`**
  - Added `extensionFields` and `extensionValues` queries.
  - Added `upsertExtensionValues` and `deleteExtensionValue` mutations.
  - Added `ExtensionField`, `ExtensionValue`, and `ExtensionValueInput` GraphQL types.
- **`plugins/core/graphql/resolver.go`**
  - Added extension service wiring via `WithExtensions`.
  - Added permission checks for read/write parity (`extensions.read`, `extensions.write`, `extensions.private.read`).
  - Delegated extension operations to `FieldService` and `ValueService` (no direct DB logic in resolvers).
- **`plugins/core/graphql/plugin.go`**
  - Wired extension field/value services in plugin initialization using postgres extension repos and shared extension registry.
- **`plugins/core/graphql/handler.go`**
  - Preserved resolver error sanitization for internal failures while allowing structured app-level validation/forbidden messages to pass through.
- **Tests**
  - Added GraphQL extension parity tests for:
    - public value round-trip,
    - private field omission without private permission,
    - mutation forbidden without write capability.
