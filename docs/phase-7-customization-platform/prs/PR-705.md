# PR-705 — Cart Item Extension Capture (Track C, OSS)

Status: planned

## Summary

- Read/write extension values on `cart_item` targets
- Cart API exposes extensions on line items (admin + storefront cart)
- PDP/add-to-cart path accepts extension payload for snapshot-eligible fields

## Why

Product-level defaults are not enough; line items need per-row custom data (gift message, engraving, selected option).

## Scope

- Extend cart application layer to validate and store cart_item values
- REST cart endpoints include `extensions` on items when present
- Storefront cart template shows public extension values (simple list renderer)
- Tests: add item with extension, update quantity preserves extensions

## Out Of Scope

- Checkout snapshot to order (PR-706)
- Computed-only fields (resolver hook later)

## Validation

- Add cart line with extension value; GET cart returns value on item
- Invalid field or type rejected at add-to-cart
- Storefront cart page displays public extension label/value
