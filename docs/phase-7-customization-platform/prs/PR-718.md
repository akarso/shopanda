# PR-718 — Reference Plugin: Slots E2E (Track F, OSS)

Status: done

## Summary

- `plugins/slotsdemo` reference plugin registers `layout.footer` and `pdp.info` renderers via `pkg/extapi`
- Integration test renders default theme product page and asserts DOM marker positions
- Opt-in via `plugins.slotsdemo.enabled` (default off; CI unchanged)

## Why

Tracks A–F shipped slot infrastructure and catalog, but plugin authors lacked a runnable end-to-end proof that renderers land in the expected DOM positions.

## Scope

- Reference plugin (`slotsdemo/reference`):
  - `layout.footer` append — identifiable `data-slotsdemo="layout-footer"` marker
  - `pdp.info` append — identifiable `data-slotsdemo="pdp-info"` marker
- Config + wiring: `plugins.slotsdemo.enabled`, `SHOPANDA_PLUGINS_SLOTSDEMO_ENABLED`, `register_plugins.go`
- Tests:
  - unit: plugin Init registers renderers
  - E2E: product page HTML order (actions before PDP marker; PDP before layout footer; footer marker inside `<footer>`)

## Out Of Scope

- Cart/checkout slot demo (catalog already covered by theme tests)
- Admin UI for slot debugging
- Runtime plugin loading

## Validation

- `go test ./plugins/slotsdemo/...`
- With plugin enabled, product pages include demo markers in documented positions
