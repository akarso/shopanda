# PR-711 — Standard Slot Catalog (Track F, OSS)

Status: done

## Summary

- Canonical slot anchor catalog in `internal/application/slots/catalog.go`
- Default theme implements all standard anchors (`layout.*`, `pdp.*`, `plp.*`, `cart.*`, `checkout.*`)
- Theme anchor scanner + tests ensure catalog and default theme stay in sync
- `PLUGINS.md` documents the catalog for plugin authors

## Why

PR-708 shipped the slot registry with a minimal marker set (PDP actions + cart summary). Plugin authors need a **predictable, documented anchor catalog** on every major storefront surface without reading theme source.

## Scope

- `slots.StandardAnchors()` / `StandardAnchorNames()` — single source of truth
- `theme.DeclaredAnchors(provider)` + `themefs.AnchorSource` — parse anchors in domain, filesystem scan in infrastructure adapter
- Default theme markers:
  - **layout:** `head`, `body_start`, `header`, `nav`, `category_nav`, `main`, `footer`, `body_end`
  - **pdp:** `gallery`, `info`, `actions`
  - **plp:** `toolbar`
  - **cart:** `items`, `summary`
  - **checkout:** `progress`, `summary`
- Tests: catalog validity, default theme declares all standard anchors, page render smoke tests
- `PLUGINS.md` slot table updated; notes nested `slot_container` limitation

## Out Of Scope

- Theme inheritance (PR-712)
- Layout partials (PR-713)
- Admin slots catalog API / dev warnings (PR-714)
- Account/home anchors (PR-715)
- Nested `slot_container` preprocessor fix (PR-717)

## Validation

- `go test ./internal/application/slots/... ./internal/domain/theme/...`
- Every `slots.StandardAnchorNames()` entry appears in `theme.DeclaredAnchors(themes/default)`
- Home, product, cart, and checkout_address templates render registered slot HTML

## What changed

- **`internal/application/slots/catalog.go`** — canonical anchor catalog
- **`internal/domain/theme/anchors.go`** — template anchor scanner
- **`themes/default/templates/`** — `cart.items`, `checkout.summary`; layout/PDP/PLP markers from Track F groundwork
- **`PLUGINS.md`** — documented catalog
- Tests: `catalog_test.go`, `anchors_test.go`, `default_theme_catalog_test.go`, expanded `default_theme_slots_test.go`
