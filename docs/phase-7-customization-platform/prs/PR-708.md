# PR-708 — Slot Registry + Storefront Markers (Track D, OSS)

Status: planned

## Summary

- Template slot anchors in default theme with four placements: `before`, `after`, `prepend`, `append`
- Plugin slot renderer registration with deterministic order per `(anchor, placement)`
- Render slots on PDP and cart views

## Why

Merchants and plugins need HTML injection points without forking `layout.html` for every feature. Four placements cover both surrounding a block and injecting inside it at start/end.

## Scope

- Slot registry service + `RegisterRenderer(anchor, placement, priority, renderFn)` on plugin port
- Placement enum: `before` | `after` | `prepend` | `append` (see spec §9.2.1)
- Theme template funcs:
  - `slot_container` / end — wraps markup and auto-emits all four surfaces
  - `slot(anchor, placement)` — explicit marker for existing DOM
- Theme templates: add anchors on PDP + cart (minimal set)
- Storefront composition loads registered renderers into page data
- Tests: each placement renders in correct position; unknown slot noop

### Placement reference

| Placement | Where injected HTML lands |
| --- | --- |
| `before` | Outside container, immediately before opening tag |
| `after` | Outside container, immediately after closing tag |
| `prepend` | Inside container, first child (right after open) |
| `append` | Inside container, last child (right before close) |

Example:

```html
{{slot_container "pdp.price"}}
<div class="product-price">{{.Price}}</div>
{{/slot_container}}
```

```go
app.Slots().RegisterRenderer("pdp.price", slot.PlacementAppend, 100, renderEcoBadge)
```

## Out Of Scope

- Admin slot configuration UI
- Every page type (start with PDP + cart)

## Validation

- Reference test plugin registers renderers for `append` and `before`; PDP HTML shows fragments in correct DOM positions
- Two renderers same `(anchor, placement)` compose in priority order
- `prepend`/`append` output appears inside the container element; `before`/`after` outside it
- Missing slot marker does not break template parse
