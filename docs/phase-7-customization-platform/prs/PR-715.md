# PR-715 — Remaining Page Anchors (Track F, OSS)

Status: done

## Summary

- Added `home.hero`, `account.nav`, and `checkout.panel` to the standard slot catalog
- Default theme markers on home, signed-in account pages, and checkout form steps
- `_account_nav.html` partial centralizes account nav with `account.nav` slot container

## Why

PR-711 established layout, PDP, PLP, cart, and partial checkout anchors. Shipped page types (home, account, checkout forms) still lacked documented injection points for plugin authors.

## Scope

- Catalog + `pkg/extapi`: `home.hero`, `account.nav`, `checkout.panel` (groups: `home`, `account`, `checkout`)
- Default theme markers:
  - **`home.html`** — `home.hero` around default hero; before/after slots when CMS blocks drive the page
  - **`_account_nav.html`** — `account.nav` on orders, returns, order detail, profile, addresses, preferences, security
  - **`checkout_address.html`**, **`checkout_shipping.html`**, **`checkout_payment.html`** — `checkout.panel` around main form panel
- `cart.items` already present from PR-711 (no change)
- Tests: catalog sync, default theme render smoke tests for new anchors

## Out Of Scope

- Login/register/verify account pages (no section nav — intentional)
- Checkout confirm page (no form panel)
- `layout.yaml` block ordering (PR-716)
- Reference plugin E2E (PR-718)

## Validation

- `go test ./internal/application/slots/... ./internal/domain/theme/... ./pkg/extapi/...`
- `theme.DeclaredAnchors` / `slots.StandardAnchorNames()` include all three new anchors
- Home, account_orders, checkout_address render new slot markers

## What changed

- **`internal/application/slots/catalog.go`** — three new standard anchors
- **`pkg/extapi/slots.go`** — stable constants + order
- **`themes/default/templates/`** — `_account_nav.html`; markers on home, account, checkout templates
- **`PLUGINS.md`** — catalog table updated
- Tests: `default_theme_slots_test.go`, `compat_test.go` (via catalog sync)
