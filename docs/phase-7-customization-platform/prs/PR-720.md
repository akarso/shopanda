# PR-720 — Slot Marker Validation (Track F, OSS)

Status: done

## Summary

- Theme startup warns when templates declare slot anchors outside the standard catalog
- Optional `frontend.strict_slot_markers` fails startup for CI/theme-author guardrails
- `slots.UnknownDeclaredAnchors` + `theme.ValidateDeclaredAnchors` helpers

## Why

PR-714 warned when plugins register anchors missing from the active theme. PR-720 closes the reverse gap: typos or undocumented custom anchors in theme templates are visible at load time instead of silently breaking plugin injection.

## Scope

- Validation helpers:
  - `slots.UnknownDeclaredAnchors()` — compare declared anchors to `StandardAnchors()`
  - `theme.ValidateDeclaredAnchors()` — warn list or strict error
- Config: `frontend.strict_slot_markers`, `SHOPANDA_FRONTEND_STRICT_SLOT_MARKERS`
- Startup wiring in `cmd/api/main.go` — log `slots.theme.unknown_anchor` per unknown anchor
- Docs: `THEME_SLOTS.md`, `config.example.yaml`

## Out Of Scope

- Failing when standard catalog anchors are missing from a theme (custom themes may omit anchors intentionally)
- Admin UI for validation results
- `layout.yaml` block ordering (PR-716)

## Validation

- `go test ./internal/application/slots/... ./internal/application/theme/...`
- Default theme: no unknown anchors
- Strict mode rejects `custom.widget` anchor

## What changed

- **`internal/application/slots/catalog.go`** — `StandardAnchorNameSet`, `UnknownDeclaredAnchors`
- **`internal/application/theme/anchors.go`** — `ValidateDeclaredAnchors`
- **`internal/platform/config/config.go`** — `StrictSlotMarkers`
- **`cmd/api/main.go`** — validation + warnings at theme marker load
- **`configs/config.example.yaml`** — documented strict flag
- **`docs/guides/THEME_SLOTS.md`** — validation section
